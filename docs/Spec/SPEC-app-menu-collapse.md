# SPEC：右键菜单打开时岛不再自动收起

日期：2026-11-25　分支：`fix-avoid-self-foreground`

## 1. 目标

岛展开状态下右键弹出应用菜单时，岛保持展开，直到菜单关闭；用户能把鼠标移到菜单项并点中「暂时隐藏灵动岛」。现在菜单刚弹出岛就缩回收起态（用户 2026-11-25 报障 + 截图）。

## 2. 修改范围

- `src/renderer/src/App.tsx`：菜单打开期间抑制「失焦收起」与「鼠标移开延时收起」；菜单关闭后按光标是否还在岛上决定收起。
- `src/preload/index.ts`：新增 `onAppMenuClosed` 事件桥。
- `src/main/index.ts`：`app:show-menu` 的 `popup()` 加 `callback`，菜单关闭后通知渲染层。
- 不改菜单条目、不改收起时长常量、不改托盘菜单。

## 3. 预期行为

1. 展开态右键 → 菜单出现，岛保持原尺寸/展开态；光标移到菜单项时岛不缩。
2. 点中「暂时隐藏灵动岛」→ 岛按原逻辑隐藏。
3. 点中「设置… / 页面管理… / 让桌宠出岛…」→ 与现在一致（打开对应窗口）。
4. 按 Esc 或点菜单外关闭菜单：光标不在岛上 → 岛收起（等同鼠标移开）；光标仍在岛上 → 保持展开。
5. 菜单未打开时的失焦收起、鼠标移开收起完全不变。

## 4. 必要依赖

无新增依赖；沿用 Electron 原生 `Menu.popup({ callback })`。

## 5. 验收条件

- 自动化：展开态触发右键（渲染层 `contextmenu`）→ 2 秒后岛窗口高度仍为展开态；关闭菜单且光标不在岛上 → 恢复收起态。
- 现有回归：`e2e-pages-custom`、`e2e-todo-today` 等与岛开合相关的脚本不回归；`typecheck` / `build` 通过。
- 真机：用户在展开态右键，菜单可正常点中「暂时隐藏灵动岛」。

## 6. 不做什么

- 不改菜单的弹出位置与样式（原生菜单）。
- 不处理托盘菜单与桌宠窗口菜单（它们不依赖岛展开态）。
