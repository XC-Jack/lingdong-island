# SPEC：真全屏时禁用「光标到顶自动唤回」（游戏被最小化的根因）

- **建立日期**：2026-11-18
- **基线提交**：`57a843a`（main，v0.1.8）
- **任务分支**：`no-reveal-in-fullscreen`
- **关联**：`SPEC-avoid-show-attribution.md`、`SPEC-fix-exclusive-fullscreen-crash.md`、`../facts/功能清单.md` 第 14 条

## 一、问题（用户自己定位到的根因）

用户在《三角洲》（独占全屏）里实测后给出结论：

> 游戏全屏后，任何软件切到或者打开，游戏都会最小化。我玩游戏时，只要**视角往上移**就会触发岛的唤起，这个时候游戏就会最小化，然后切到桌面。

即「每隔几分钟突然切到桌面」的真实触发链是：

1. 游戏独占全屏运行 → 岛被正确隐藏（无窗口创建，v0.1.7 起）
2. 玩家把视角往上抬 → **鼠标（系统光标）被顶到屏幕最上边** y≈0
3. 我们的「摸边唤回」判据就是「光标 y ≤ 2」→ 认为用户想调出岛 → `show` 岛
4. 独占全屏上出现置顶窗口 → 游戏立刻最小化 → 用户看到「切到桌面」

这条链解释了全部现象：为什么是周期性的（视角上抬的频率）、为什么只有全屏模式（无边框窗口不敏感）、为什么「不隐藏」档也不出问题（岛一直可见时游戏本来就容忍那个窗口存在，且不会反复 show）。

## 二、目标

**在真全屏（judge=F）期间不做「光标到顶自动唤回」**，其它场景（最大化 Z、普通窗口 N）保持原样：

- 游戏/全屏视频期间，光标顶到屏幕边不再唤出岛 → 不会把游戏最小化
- 平时（最大化窗口）摸边唤回照旧，手感不变
- 真全屏期间要看岛：退出全屏（Alt+Tab / 游戏窗口化）后岛自己回来，或（游戏窗口化时）用托盘/摸边

## 六、不做什么

- 不删「摸边唤回」这个功能（只在真全屏下禁用）；不加新设置项（先按此行为跑一版，用户觉得全屏里也要能唤回再谈）。
- 不改判定逻辑（不允许用「进程名白名单」之类的方式识别游戏）。
- 不在 `main` 上直接提交。
