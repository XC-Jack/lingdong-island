# SPEC：展开态头部改成两行（标题一行、状态一行）

## 一、目标

解决展开态头部「太挤」：以 2026-11-18 置物架页截图为例，日期档时钟 `11/18 周三 19:38` 被 50% 宽的绝对居中盒挤成三行，并与左侧「置物架」标题、电量环重叠。

改法：把展开态头部拆成上下两行——第一行是「徽章 + 页面标题 + 岛仔 + 右侧完成度」，第二行是「按用户顺序排列的状态组件（电量环 / 时钟 / 网络 / 待办 / 铃铛）」，第二行整行居中、独占横向空间。

## 二、修改范围

| 文件 | 改动 |
|---|---|
| `src/renderer/src/App.tsx` | 展开态 `.panel-head` 内新增 `.head-top` 行；`.head-pet` 从 `.head-status` 移到 `.head-top`；`.head-status` 只保留 `.head-info` |
| `src/renderer/src/styles.css` | `.panel-head` 改列向；新增 `.head-top`；`.head-status` 取消绝对定位、改为整行居中的第二行；`.head-pet` 绝对定位到头部上沿居中；`.head-status .collapsed-pet` → `.head-pet .collapsed-pet` |

不改：收起态胶囊、状态组件的渲染顺序/显隐逻辑、主进程窗口尺寸、prefs 结构。

## 三、预期行为

1. 展开任意页：第一行显示页面徽章、标题、岛仔、右侧完成度；第二行居中显示状态组件，顺序与「页面管理」里的设置一致。
2. `dateWeek` 档时钟在展开态完整显示为一行（如 `11/18 周三 19:38`），不换行、不与标题或电量环重叠；收起态胶囊里的时钟保持原样。
3. 状态行与第一行之间留 8 布局 px，状态行与头部下边框之间保留原有 14 布局 px。
4. 岛宽仍为 340 布局 px 最小宽（视觉 255），不因新布局变宽。

## 四、必要依赖

无新增依赖。

## 五、验收条件

| 编号 | 条件 |
|---|---|
| A1 | `e2e-head-order` 全过（H1/H3/H5/H6），特别是 H5a 状态区与标题不重叠 |
| A2 | `dateWeek` 档下 `.collapsed-clock` 在展开态 `scrollWidth === clientWidth`、单行、无换行 |
| A3 | 展开态岛宽不变（isolated 环境实测 255 视觉 px / 340 布局 px） |
| A4 | 置物架、待办、音乐三页截图目视无重叠、无贴边 |
| A5 | `npm run typecheck` 通过 |
| A6 | 收起态截图与改动前一致（组件位置、胶囊高度不变） |

## 六、不做什么

- 不调整状态组件本身的尺寸（电量环 27、时钟 17.5、Wi-Fi/铃铛 18 保持）。
- 不改「页面管理」的顺序/显隐语义，不改收起态布局。
- 不借机改各页内容区的间距、配色。
- 不改主进程窗口的最小/最大尺寸。
