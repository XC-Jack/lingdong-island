# SPEC：每页固定尺寸，页内不再伸缩

- 建立日期：2026-11-24
- 基线：`island-no-pager` `ef7b574`
- 任务分支：`island-no-pager`
- 背景：用户看完预览给出三条连续反馈——
  1. 「这个代办页就做如图这么大」：待办页按截图（3 条任务）的尺寸固定；
  2. 「现在每个页面不要再做伸缩了，伸缩老是卡」：页内内容变化、开关浮层都不再改变窗口尺寸；
  3. 二选一时明确选「每页各自固定」：待办固定为截图大小，其他页面各自固定成自己的尺寸；切页时窗口仍会换一次尺寸。

## 一、目标

1. 岛展开态宽度统一固定 340 布局 px（视觉 255）。
2. 每个页面有固定的岛高，页内任务增减、文件增减、通知增减、开关浮层都不改变岛尺寸。
3. 待办页固定为截图那档尺寸（岛 340×310 布局 px ≈ 视觉 255×232.5）。
4. 浮层不再把岛撑高：待办的日期/时间浮层改为岛内展开；删除 `popFit.ts` 的撑高机制。

## 二、修改范围

| 文件 | 改动 |

| `src/renderer/src/styles.css` | 岛展开态改固定宽 340；按页固定高度；待办日期/时间浮层改为岛内定位并压缩月历/时间列 |
| `src/renderer/src/popFit.ts` | 删除（不再使用） |

## 三、预期行为

1. 展开态固定尺寸（布局 px，屏幕 px = ×0.75）：

   | 页面 | 岛高 | 视觉高 |
   | --- | --- | --- |
   | 组件网格 | 330 → **362** | 247.5 → **271.5** |
   | 待办 | 310 | 232.5 |
   | 置物架 | 251 | 188.3 |
   | 通知 | 292 | 219 |
   | 日程 | 339 | 254.3 |
   | 音乐（无歌词栏） | 292 | 219 |

   宽度全部 340（视觉 255）。

   > **后续变更（2026-11-27 `SPEC-widget-drag`）**：组件网格五张卡改成等大后，
   > 从「两行方格 + 一条矮宽卡」变成三行 88 高方格，网格高度由 330 抬到 **362**（视觉 271.5），
   > 透明玻璃主题 386。其余页面的高度未变。实测（2026-11-27 探针）：展开网格时窗口 256×273、
   > 岛 255×271.5，`.widget-grid` 内容 231×241.2。[实测]

2. 页内变化不改尺寸：待办 0/1/3/6 条、置物架 0/1/4/5/8 个文件与大/列表两视图、通知消息增减、日程打开当天浮层、待办打开日期/时间浮层，岛均保持该页固定尺寸。
3. 待办浮层在页面内部展开：日期月历格子压到 20×20、间距 1px，浮层贴页面底部往上盖；时间浮层留在输入行下方，两列高度 112 布局 px。两者都不越过岛底。
4. 切页仍会改变窗口尺寸一次（用户明确选择「每页各自固定」），页内不再反复伸缩。
5. 例外：音乐页点「词」进入歌词模式时保留原有并排布局，岛回到内容尺寸（约 535 布局宽、358 高）；关歌词后回到固定尺寸。这是用户主动切换的模式，不算日常内容伸缩。

## 四、必要依赖

无。`fitIslandToPopover` 所依赖的 `--pop-extra` 一并去掉，`padding-bottom` 恒为 20。

## 六、不做什么

- 不把所有页面统一成同一个尺寸（用户已否掉这个选项）。
- 不重做音乐歌词布局，不改数据与 IPC。
- 不合并 `main`、不打包、不发版。
