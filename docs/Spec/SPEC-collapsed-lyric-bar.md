# SPEC：收起态歌词条

> 分支：`collapsed-lyric-bar`（基线 `main` `ad8d8c4`）
> 相关事实：`docs/facts/功能清单.md` 第 5 节（收起态状态栏）、第 17 节同段音乐功能；`docs/facts/数据规则.md` 的 `prefs.json` 字段；`docs/facts/视觉设计规范.md` 色彩/字体/形状。
> 用户 2026-11-27 原话：「行，就做这个」（指收起态歌词条）。

## 一、目标

播放音乐时，让收起态胶囊直接显示当前一句歌词（参考视频里的「歌词条」），不用展开岛就能跟唱/扫一眼。收起态目前只有时间、电量、网络、待办、铃铛；这是视频里有、本项目一直标着「仍未做」的最后一项音乐能力。

参考视频（`d:\Users\honor\Downloads\15期丨…mp4`，约 68–80 秒）的形态：整条胶囊切成 **封面 + 岛仔 + 当前一句歌词 + 右侧节奏图标**，时间/电量等状态组件暂时让位；不播放时恢复普通胶囊。

## 三、预期行为

### 3.1 何时出现

同时满足才切歌词条：

- 岛处于**收起态**；
- 设置里「收起胶囊显示歌词」为开；
- 音乐状态 `active === true`（播放或暂停都算，暂停时保留当前句方便看词）；
- 歌词已拿到且至少有一句（`lyric.ok && lines.length > 0`）。

任一不满足就回到原来的状态组件行（时间/电量等）。**没歌词绝不编造**：纯音乐、搜不到、查询中，都显示普通胶囊。

### 3.2 外观（对照视频，按本项目 0.75 缩放）

- 胶囊高度不变（52 布局 px / 39 视觉 px），宽度固定 **400 视觉 px**，不随歌词长短跳动。
- 从左到右：
  1. 封面 30×30 布局 px、圆角 8；无封面时显示音符占位；
  2. 岛仔（仅当「页面管理 → 收起态组件 → 岛仔」开着，且 `petMode === 'island'`）；
  3. 当前歌词单行，居中，字号 15 布局 px、字重 700；未到第一句时显示第一句但降透明度；过长右侧省略号，`title` 给全文；
  4. 右侧**播放/暂停按钮**（2026-11-28 第三轮替换原来的三根竖条节奏动画）：播放中显示暂停图标、暂停时显示播放图标，图标在按钮内垂直居中，悬停变亮。
- 颜色只走 token：文字 `--ink-1`，占位底色用表面档，播放/暂停图标用 `--ink-1` 的透明度档；四套主题都成立。

### 3.3 当前句

- 取「开始时间 ≤ 当前播放位置」的最后一行；位置与音乐页同一套口径：
  - 播放器报时长（`duration > 0`）：快照位置 + 快照后真实流逝时间（最多补 0.9 秒）；
  - 播放器不报时长（网易云）：复用模块级进度钟 `clockNow()`（`ensureClockWatcher()` 常驻订阅）。
- 换歌重新查歌词；查歌词失败按 3.1 回落普通胶囊。
- 暂停时停在最后一句，节奏图标静止；音乐会话消失（关掉播放器）恢复普通胶囊。

### 3.4 设置与资源

- 新开关「收起胶囊显示歌词」默认开。
- 开启时，收起态需要持续读音乐状态：渲染层在挂载期间维持音乐桥接的「有人用」租约（`musicDemand`）并在必要时重新拉起桥接；展开后不再续租，桥接按既有 2 分钟空闲规则回收。
- 代价如实写在设置说明里：**音乐检测常驻约 100 MB 内存**；关掉开关即回到按需启动。
- 不做进程探测之类的隐式判断，行为可预期：开关＝是否常驻。

### 3.5 交互

- 点歌词条的其它区域等同于点胶囊：展开岛（沿用岛根现有 `toggle()`）。
- **右侧播放/暂停按钮**（2026-11-28 第二轮改成按钮；第三轮把三根竖条换成播放/暂停图标）：点它调 `music:control` 的 `toggle`，并 `stopPropagation`，不会顺带展开岛；悬停变亮、带「暂停 / 继续播放」提示与无障碍名。其余区域仍是展开。
- 不改变展开态音乐页任何行为。

### 3.6 进出动效

- 歌词条进出时，`.island` 的**宽度过渡临时关闭**（`lyric-snap` 类，300ms）：窗口宽度是主进程一次性 `setBounds`，若岛还按 220ms 过渡，ResizeObserver 会在过渡中量到中间宽度、窗口一截一截地追，右边先被裁掉再补上（2026-11-28 用户「有卡顿，不完整」）。
- 关过渡后，渲染层在类名刷进 DOM 后按最终宽度立即上报一次（两个 `requestAnimationFrame`），窗口与岛同帧到位；内容再补 160ms 淡入，避免「啪」地跳出。
- 只关宽度过渡；高度、圆角、`--island-lit` 的过渡不变。淡入**始终播放**（2026-11-28 用户要求不跟随系统 `prefers-reduced-motion`，见 `docs/Spec/SPEC-island-motion-always.md`）。

### 3.7 歌词态 ↔ 展开态之间不做尺寸动画（2026-11-28 第三轮）

- 用户原话：「在歌词状态下，我点击岛，就是在切换回岛的形态和滚动歌词之间，就是会有这种抖动效果，以后不要添加了，老是卡顿，画面显示不完整。」
- **原因 [实测代码路径]**：歌词条宽 400 视觉 px，展开态固定 255 视觉 px，点开时宽度是**变窄**。现有展开入场逐帧插值只在「宽、高都变大」时生效（`to.w > from.w && to.h > from.h`），宽度变窄时整段被跳过：岛停在 300 视觉 px 而窗口缩到 255，右边被裁；收起时岛受 `transition:none` 立刻变宽到 400，窗口却还在 220ms 补间里，同样被裁。
- **改法**：只要切换发生时处于歌词模式（有歌且查到词），**展开与收起都一步到位**：
  - 渲染层临时关闭 `.island` 的 width/height 过渡（约 400ms），按最终尺寸量一次并上报；
  - 跳过 `island-entrance` 入场动画与逐帧插值，直接请求主进程按目标矩形 `setBounds`（不走 220ms 补间）；
  - 主进程 `island:set-expanded` 增加 `instant` 参数，`true` 时走 `applyBoundsNow`；已在补间中也会被它截停。
- 非歌词模式的展开/收起保持原动画，不受影响。歌词模式进出（开始/暂停、开关）仍沿用 3.6 的 `lyric-snap`。

- 不做滚动歌词条 / 双击复制歌词 / 点击跳转音乐页（保持点胶囊=展开）。
- 不改展开态音乐页、歌词面板、桌面歌词开关。

- 不动通知/验证码/更新横幅的布局与优先级。

## 七、已知取舍

- 歌词条宽度固定 400 视觉 px，比普通胶囊（约 217）宽一截；这是为一句歌词可读性做的取舍，与参考视频一致。窄屏（<1280）也未超出安全范围。
- 常驻桥接的内存代价（约 100 MB）由用户用开关决定；默认开是为了交付即可用。
- 暂停时保留歌词条，时间/电量暂时不可见；要回到普通胶囊可关掉播放器或关闭开关。
- **歌词源覆盖不到的上传曲不会有歌词条**（2026-11-28 实测）：汽水音乐里歌名被写成歌词首句的翻唱/上传版（例：「过完整个夏天（忧伤并没有好一些）」/ 池袋西口，实为周传雄《黄昏》），网易云能搜到该上传版但没有词、lrclib 无收录，`lyricGet` 返回 `ok:false`，按 3.1 回落普通胶囊。虽然播放器自己的界面有词，但本项目只认歌词源，不读播放器 UI。当时探到 QQ 音乐接口能按歌词句命中原曲，但用户 2026-11-28 明确选择「保持现状」，不新增第三方歌词源。
