# SPEC-美化-03 展开态头部同步组件顺序（岛仔单独置顶）

- 建立日期：2026-11-08
- 对应基线提交：`a5c28b8`（main，已含美化-02 合并 `0acbd67`）
- 任务分支：`beautify-03-head-order`
- 关联用户故事：无独立编号（美化系列，延续美化-02 的 `pagesCustom.order`）
- 关联事实文档：`../facts/功能清单.md` 第 11 节（收起态组件显隐与顺序）

## 一、目标

展开态（点开岛之后的头部）现在把「岛仔 + 时钟 + 电量环」写死并整体绝对居中，用户改过的组件顺序/显隐在展开态看不到效果。本次让展开态头部也按同一套 `pagesCustom`（显隐 + 顺序）渲染，**但岛仔不参与排序**——岛仔单独升到信息行上方一层（用户 m00599：把岛仔放到信息展示的上方）。

## 二、修改范围

- `src/renderer/src/App.tsx`：抽出可复用的「状态组件」渲染函数（电量环 / 时钟 / 网络 / 待办剩余 / 铃铛），收起态与展开态共用；展开态 `.head-status` 由写死三件改为「岛仔（单独一行）+ 按 order 排列的信息行」。
- `src/renderer/src/styles.css`：`.head-status` 改为纵向两层、新增 `.head-pet` / `.head-info`；头部内各组件的尺寸覆盖（比收起态略小）。
- `scripts/e2e-head-order.mjs`（新建）：断言展开态信息行顺序 = `pagesCustom.order`、开关生效、岛仔在信息行上方且不在信息行内、铃铛按未读出现、无数据不渲染。
- `scripts/e2e-wifi.mjs`：A4 断言**语义变更**。原断言是「展开态不出现网络图标」，本轮需求明确要求网络图标同步进展开态头部，两者直接冲突；改为「展开态的网络图标必须位于 `.head-info` 内（不得散落到面板其它位置），且与收起态显隐一致」。这是需求要求的语义变更，不是为了让测试变绿而放宽。
- `docs/facts/功能清单.md`：第 11 节补一句「展开态头部同步」。
- 不改：收起态胶囊（含其顺序/显隐/拖动交互）、页面管理面板、数据层 `prefs.json` 结构与 IPC 通道、横幅、通知页/待办页/日程页/置物架页的内容区。

## 三、预期行为

1. 展开岛后，头部中间区域变成上下两层：**上一层是岛仔**（水平居中），**下一层是信息行**——电量环、时钟、网络、待办剩余数字、铃铛，按「页面管理」里设定的顺序从左到右排列，与收起态一致。
2. 「页面管理」里取消勾选的组件在展开态同样不出现；岛仔的勾选框仍然控制岛仔是否出现（但它永远在最上方一层，不进入信息行的排序）。
3. 各组件沿用收起态的「无数据不渲染」语义：读不到电量不画电量环、读不到网络不画网络图标、待办全部做完不显示剩余数字、无未读不显示铃铛。
4. 头部左侧的页面徽章 + 页名、右侧的自启开关、待办页右下角的 `已完成/总数`（`0/0`）位置不变。
5. 展开态内组件的字号/尺寸比收起态略小（头部信息行 12.5px 量级、电量环 20px），保证不挤压标题行。

## 四、必要依赖

无新增依赖（纯 React 条件渲染 + CSS，图标沿用既有 SVG 组件）。

## 五、验收条件

- [ ] H1 展开态存在 `.head-info`，其子元素顺序与 `prefs.json` 的 `pagesCustom.order` 一致（过滤未勾选与无数据项）。
- [ ] H2 取消勾选某组件后，展开态信息行不再渲染该项；重新勾选后恢复。
- [ ] H3 岛仔（`.head-pet` 内的 `.collapsed-pet`）的 `getBoundingClientRect().top` 小于信息行的 `top`（确实在上方），且岛仔**不在** `.head-info` 的子元素里。
- [ ] H4 有未读时信息行出现铃铛，无未读时不出现。
- [ ] H5 头部不溢出、不裁切：`.panel-head` 内各元素矩形互不重叠（标题/岛仔/信息行/自启开关），且 `.head-status` 完整落在 `.island` 内。
- [ ] H6 既有回归全 PASS：`e2e-collapse-order.mjs`（22 条）、`e2e-collapse-beautify.mjs`、`e2e-collapsed-todo.mjs`、`e2e-pages-custom.mjs`、`e2e-todo-today.mjs`、`e2e-wifi.mjs`。
- [ ] H7 `npm run typecheck` + `npm run build` PASS；打包装机后 `D:\软件\灵动岛\` 4 进程存活，安装版展开态顺序与设定一致。
- [ ] [人工] 用户实机看展开态头部：岛仔在上、信息行在下、顺序与胶囊一致。

## 六、不做什么

- 不把岛仔改成可排序项（用户明确「岛仔除外」）。
- 不改收起态胶囊的任何视觉与交互。
- 不改「页面管理」面板的选项与拖动语义（页面区仍是互换，组件区已是插入）。
- 不移除待办页右侧的 `已完成/总数`（`0/0`）——与本轮信息行的「剩余件数」语义不同，保留。
- 不改横幅、通知页、日程页、置物架页。
- 不改 `prefs.json` 结构与 IPC 通道。
- 不顺手修本轮发现但与头部无关的问题。
