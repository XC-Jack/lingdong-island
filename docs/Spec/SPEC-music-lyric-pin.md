# SPEC-music-lyric-pin：歌词面板打开期间岛不自动收起

- 日期：2026-11-18
- 分支：`island-ux-tweaks`（与时钟日期、桌面歌词同一批，三个提交各自独立）
- 背景：用户 2026-11-18「我点开了歌词面板，他会一直打开，除非我点击桌面，或者点击歌词 ui 让他缩回去……我现在发现我展开后，我不动他他过一会就自己缩回去」。现状：鼠标离开岛 700ms（`.todo-panel` 页 4 秒）后 `scheduleCollapse()` 定时收起，与歌词面板无关。

## 一、目标

歌词面板（`MusicPanel` 的 `lyricOpen`）打开时，**鼠标离开不触发定时收起**；只有点桌面/其他窗口（窗口失焦）或再点「词」/面板 × 才收起。

## 二、修改范围

| 文件 | 改动 |
|---|---|
| `src/renderer/src/App.tsx` | `MusicPanel` 增加 `onLyricOpenChange` 回调（含卸载时复位）；`App` 用 ref 记「歌词面板开着」；`scheduleCollapse()` 的定时器到点时若该 ref 为真则直接返回 |

**不改**：失焦收起（`onWindowBlur`）逻辑、`AUTO_COLLAPSE_MS`/`SHELF_COLLAPSE_MS` 数值、全屏避让、输入框聚焦保护、其他页面的收起行为。

## 三、预期行为

1. 打开歌词面板后鼠标移出岛：岛保持展开，等多久都不收。
2. 点桌面/其他程序：照常立即收起（失焦路径不受影响）。
3. 再点「词」或面板右上角 ×：面板关闭；此后鼠标离开按原规则收起。
4. 打开面板后切到别的页（音乐页卸载）：面板状态消失，岛按原规则（鼠标离开 → 定时收起）工作。

## 四、必要依赖

无。

## 五、验收条件

| 编号 | 条件 |
|---|---|
| A1 | `npm run typecheck`、`npm run build` EXIT=0 |
| A2 | 打开歌词面板、鼠标移出 → 3 秒后岛仍为展开态（`expanded === true`） |
| A3 | 面板开着时再点「词」→ 面板收起；随后鼠标移出 → 700ms 后岛收起 |
| A4 | 不开面板时回归：鼠标移出 → 700ms 后照常收起 |
| A5 | 面板开着时窗口失焦（模拟 `island:window-blur`）→ 岛收起 |

## 六、不做什么

- 不改「点桌面收起」的即时性。
- 不把面板状态持久化到下次启动。
- 不改其他页的收起时长。

## 七、自检记录

自检日期 2026-11-18，分支 `island-ux-tweaks`，dev 构建 + 隔离 userData；鼠标进出用 CDP `Input.dispatchMouseEvent` 真实指针事件（合成 `mouseout` 触发不了 React 的 leave，第一次探针因此误判）。

| 编号 | 结果 |
