# SPEC：其余四页统一组件视觉

- 建立日期：2026-11-24
- 基线：`island-widget-grid` `2bdcda0`（组件网格试水，用户已验收「没什么问题」）
- 任务分支：`island-widget-pages`（从 `island-widget-grid` 切出；网格改动尚未合并 `main`，故基线偏离 `main`）
- 背景：上一轮只把待办页做成组件风，用户确认后要求「继续往下」，即把置物架、通知、日程、音乐四页铺到同一套视觉语言。

## 一、目标

四页与待办页统一成一套 iOS 组件语言，不改结构、不改功能：

1. 内容单元统一用 16px 圆角卡片（行、格子、面板块）。
2. 工具条与输入控件统一成圆形/胶囊（视图按钮、清空、已读、输入框、时间按钮）。
3. 空态做成一张居中的卡片，而不是一行灰字。
4. 三套主题（`glass-light` / `glass-dark` / `mono`）下都成立，颜色只走 token。
5. 保留所有既有 class 名与 DOM 结构，e2e 不需要改脚本。

## 二、修改范围

| 文件 | 改动 |
| --- | --- |
| `src/renderer/src/styles.css` | 置物架、通知、日程、音乐四页的圆角/内边距/按钮形状/空态卡面 |
| `docs/facts/视觉设计规范.md` | 补「四页组件化」的统一规则 |
| `docs/状态.md` | 本轮交付记录 |

**不动**：`App.tsx` 结构、任何交互逻辑、网格页、待办页（上一轮已改）、窗口尺寸逻辑。

## 三、预期行为

1. 四页功能与交互与改动前一致；只有圆角、间距、按钮形状、空态呈现变化。
2. 置物架：视图按钮为圆形，清空按钮为胶囊，列表行为 16px 圆角卡片，空态为一张卡片。
3. 通知：列表行为 16px 圆角卡片、行距加大，工具条按钮同置物架，空态为一张卡片。
4. 日程：月历块圆角 16 且卡面更实，日期格子接近圆形，输入框与时间按钮为胶囊/圆形。
5. 音乐：封面圆角加大，播放控件与进度条延续胶囊语言。
6. 三主题下文字对比度不下降；列表仍按原条数上限滚动。

## 七、自检记录

### 7.1 实际改了什么（[实测]，2026-11-24）

| 页面 | 改动 |
| --- | --- |
| 置物架 | 视图按钮 7px 圆角 → 圆形；清空按钮 → 胶囊；列表行圆角 10→16、内边距 9/12；文件格圆角 10→16；空态一句提示改成居中卡片（ink 5%） |
| 通知 | 列表行圆角 10→16（**行高 31px、padding 4px 8px 不动**，`e2e-notify-compact` C1 精确断言）；空态卡片化 |
| 日程 | 月历块圆角 12→16、内边距 4→8；日期格子圆角 8→50%；输入框改胶囊；时间按钮在其作用域内改圆形 |
| 音乐 | 封面圆角 16→20；空态复用 `.notify-empty-inner`，自动跟着卡片化 |
| 共同 | 卡面/空态统一用 `color-mix(ink N%)`，不用 `--surface-1`：`glass-dark` 主题没单独定义 surface，会落到 `:root` 的 30% 白，在深色岛上会发亮成灰板 |

### 7.3 没验证的

- 置物架有文件时的网格/列表观感（测试数据为空）。
- 音乐页有播放内容时的封面与控件排布（当前没有在放歌）。
- 高 DPI、多显示器、真实壁纸下的观感；用户主观判断（等用户看预览版）。

### 7.4 已知取舍

- 通知行只改了圆角，行高与内边距保持原值（e2e 精确断言）；因此通知页视觉上仍比待办页紧凑。
- 音乐页只调了封面圆角，未给整块播放器加卡片容器（结构不动的前提下，避免与岛体玻璃叠成两层）。
