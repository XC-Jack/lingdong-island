# SPEC：重做岛打开/收起的动画

- 建立日期：2026-11-25
- 基线：`island-no-pager` `78f33ee`
- 任务分支：`island-no-pager`
- 用户原话：「岛打开和关闭的时候这个震动的动画换一个，震动的动画容易卡」。

## 一、目标

展开/收起不再出现横向过冲、逐帧窗口抖动和面板被裁；观感换成「窗口快速展开 + 岛淡入缩放」，时长从 500ms 收到 220ms。

## 二、修改范围

| 文件 | 改动 |
| --- | --- |
| `src/main/index.ts` | 开合补间 500ms → 220ms；渲染层先上报目标尺寸再 `set-expanded`；`expandedSize` 初始值改为组件网格 255×248；删除无效的 `webContents.invalidate()` 尝试 |
| `src/renderer/src/App.tsx` | 展开前临时关过渡量目标尺寸；`entrance` 入场状态与 `island-anim-open/close` 类；动画期间 ResizeObserver 不上报，结束后补一次真实尺寸 |
| `src/renderer/src/styles.css` | `island-open` / `island-close` 关键帧与类 |
| `docs/状态.md`、`docs/facts/视觉设计规范.md` | 同步规则与记录 |

## 三、预期行为

1. 打开：窗口从收起尺寸单调补间到当前页面尺寸（220ms，easeOutCubic），岛同时 0.9→1 缩放、0→1 淡入；没有「先变宽再缩回」。
2. 收起：窗口单调缩回收起尺寸（220ms），岛 0.94→1 缩放、0.4→1 淡入成胶囊。
3. 展开前后的窗口尺寸必须精确等于岛的目标尺寸（不按过渡起点、不按缩放中的 rect 上报）：网格 255×248，收起 168×76（随收起态内容宽度变化）。
4. 切页（网格 ⇄ 功能页）仍是一次性 `setBounds`，与 `nav-snap` 配套，不受开合动画影响。
5. 缩放/淡入期间不允许出现岛被窗口裁掉的空白条。

## 四、必要依赖

无。

## 五、验收条件

- A1 `typecheck` / `build` 通过。
- A2 逐帧探针：展开时窗口宽高单调不减，最终精确 256×248（岛 255×247.5），收起最终 170×76（胶囊 168×39）。
- A3 真屏幕帧：焦点在岛上时（真实鼠标点击）展开后能看到完整网格，没有空白/裁切。
- A4 回归：页面管理、待办、日程、通知、置物架、音乐 e2e 全过。
- A5 用户预览确认手感。

## 六、不做什么

- 不做「窗口一次 setBounds + 纯 CSS 动画」：实测透明窗跳变后合成器几百毫秒不呈现新画面（见自检 4），画面会空白。
- 不改页面切换、组件 FLIP、淡入时长。
- 不改收起态内容与尺寸规则。
- 不合并 `main`、不打包、不发版。

## 七、自检记录（2026-11-25）

1. `typecheck` / `build` 通过 [实测]。
2. `.tmp/motion-probe.mjs` [实测]：
   - 展开：窗口 170×76 → 256×248（单调；原先 170→271→256 的宽度过冲消失），岛 scale 0.9→1、opacity 0→1，约 220ms 结束；
   - 收起：窗口 256×248 → 170×76，岛 0.94→1、opacity 0.4→1，约 180ms 结束；
   - 结束尺寸精确，不再出现之前的 244 高（缩放中的 rect 被当成目标尺寸）。
3. 真实鼠标点击 + 真屏幕抓帧（`.tmp/expand-frames3/`）[实测]：`f04` 能看到完整网格，窗口位置与岛居中一致。
4. 失败记录（已回退）：先把开合改成「窗口一次 setBounds + 岛内动画」。探针与真屏幕帧显示，透明置顶窗口跳变后约 0.7–1.2s 内屏幕不呈现新画面（全空），与 `main/index.ts` 里横幅那条例外注释一致；因此保留逐帧补间，只缩短时长。
5. 回归 [实测]：`e2e-pages-custom` 7/0、`e2e-todo-today`、`e2e-schedule-day`、`e2e-notify`、`e2e-music` 17/0/3 跳过、`e2e-shelf-view-pref` 全过；快速切页探针问题帧数与上一轮持平。
6. 未验证：
   - 失焦收起的屏幕呈现：自动化环境里 `SetForegroundWindow` / 启动记事本都没能让岛失焦，未能逐帧确认真实点桌面收起后的画面；
   - 真机手感、高 DPI、多显示器；
   - 拖文件悬停展开（`island:drag-hover`）在窗口未被激活时的呈现。
