  2. 「音乐已暂停，音乐页就不显示音乐播放了」——附截图：暂停 + 网易云收进托盘时，音乐页变成「现在没有在放歌」空态

## 一、目标

1. 音乐页封面跟随当前歌曲更新，不再停留在第一首。
2. 暂停音乐（含网易云收进托盘/窗口隐藏、未开调试端口的场景）时，音乐页仍显示这首歌、状态为暂停，而不是空态。

## 二、修改范围

| 文件 | 改动 |
|---|---|
| `src/main/neteaseCdp.ts` | ① 曲名/歌手改从 `.main-title .cmd-space` / `.author` 的 `textContent` 读取（`innerText` 在播放栏不可见时返回空串，导致曲目键恒为 `"|"`）；② `fetchNeteaseCover` 去掉 `imageView` 空参数（保留时网易云忽略 `param=200y200`，返回 1425×1425 / 310 KB 原图；去掉后 200×200 / 10 KB） |
| `src/main/musicStore.ts` | CDP 封面缓存键从 `title|artist` 改为**封面 URL**：封面地址一变就重新抓，不再依赖曲名解析是否成功 |
| `src/main/smtcScript.ts` | 桥接降级路径记住最近一次识别到的曲目（`music/last-song.json` 落盘）；当播放器进程仍存活、但音频会话已撤掉且窗口标题读不到（收进托盘/隐藏）时，仍以「暂停」状态返回这首歌 |
| `docs/facts/功能清单.md` | 音乐页补「暂停/收进托盘仍显示当前歌曲」说明 |
| `docs/状态.md` | 顶部一句话状态 |

**不动**：SMTC 主路径、CDP 控制（播放/上一首/进度/音量/桌面歌词）、渲染层布局与歌词、页面管理、设置页。

## 三、预期行为

1. 播一首歌 → 音乐页显示它的封面；点下一首/自动切歌 → 封面跟着换，不残留上一首或第一首。
2. 网易云播歌 → 按暂停（岛按钮、网易云、键盘媒体键任一种）→ 音乐页仍显示歌名/歌手/封面，播放按钮变为「播放」。
3. 网易云暂停后把窗口收进托盘（或最小化）→ 音乐页仍显示这首歌（暂停态）；只有进程真正退出后才回到「现在没有在放歌」。
4. 岛的启动顺序不影响：先暂停并收进托盘、再启动岛，也显示上次播放的歌曲（`last-song.json` 有记录时）。
5. 换歌后封面抓取较快：请求的封面是 200×200（约 10 KB），不再是原图（约 310 KB）。

## 四、必要依赖

无新增依赖、无新增系统工具、不改行协议字段。

## 五、验收条件

- [ ] `npm run typecheck` 通过。
- [ ] `npm run build` 通过。
- [ ] 实测换歌：连续切换 ≥2 首歌，`musicGet()` 返回的 `cover` 每次不同，且与网易云页面 `<img src>` 对应。
- [ ] 实测暂停：网易云暂停且窗口收进托盘、未开调试端口时，`musicGet()` 仍返回 `active=true`、`playing=false`、歌曲名不为空。
- [ ] 实测冷启动：暂停+托盘状态下重启岛（桥接重新拉起），音乐页仍显示上次歌曲（`last-song.json` 已存在时）。
- [ ] 网易云进程退出后，`musicGet()` 回到 `active=false`。
- [ ] 封面请求返回 200×200 尺寸。
- [ ] 真人预览版：切歌看封面、暂停/收托盘看页面。

## 六、不做什么

- 不改 SMTC 正常路径、不改 CDP 控制命令与桌面歌词。
- 不做封面落盘缓存、不做封面动画。
- 不新增「记忆播放器」以外的状态持久化，不把暂停态伪装成播放态。
- 不顺手改歌词、布局、页面管理。
