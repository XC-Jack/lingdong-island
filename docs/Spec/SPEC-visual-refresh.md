# SPEC：视觉换皮第一步（不改结构）

- 建立日期：2026-11-24
- 基线：`switch-size-sync` `a98d191`（切页尺寸同步修复，用户机器上跑的 0.4.3 就是它）
- 任务分支：`visual-refresh`
- 背景：用户 2026-11-24 原话「我的岛做起来不高级……有一种几十年前那种年代味」，要「简约高级的感觉」。商定先只换皮肤、不动结构，方向确认后再做组件化与统一尺寸（第二步）。

## 〇、问题（[实测]，2026-11-24 截图 + 代码）

五个页面截图逐一看过，判为「旧」的具体来源：

1. 底色纯黑 `rgba(9, 9, 11, 0.97)`（`styles.css:51`），配近白文字 `#f2f3f5`（20 处），是 2010s OLED 审美。
2. 强调色为饱和紫系：`#8b5cf6` / `#9f8bff` / `#b9a8ff` / `#8b6bff` 等（10+ 处）。
3. 待办页头部一行挤 7 个元素（图标、标题、岛仔、0/0、电量环、时间、WiFi、铃铛），岛宽仅 256 视觉 px。
4. 层次靠描边与分隔线：`rgba(255,255,255,0.06~0.14)` 共 40+ 处，缺少明暗差。
5. 圆角六种混用：7/8/9/10/12/14/16。
6. 字号偏低：9/10/10.5/11/12 大量用于正文。

## 一、目标

**只改视觉表现，不动任何结构与交互。** 让五个页面和收起态一起换成一套统一的、克制的新皮肤：

1. 底色改为带冷调的深灰，降低与文字的直接对比。
2. 层次改成「表面亮度分层」（三层白叠加），删掉大多数内部描边与分隔线。
3. 强调色换成单一低饱和蓝，紫色系全部退出。
4. 字号整体上调一档，字重分出三档。
5. 圆角收敛成三档：外框 24 / 卡片 16 / 控件 10（胶囊标签仍 999）。
6. 建立 CSS 变量（token），后续第二步改结构时直接复用。

## 二、修改范围

| 文件 | 改动 |
| --- | --- |
| `src/renderer/src/styles.css` | 新增 `:root` token；替换底色、文字色、强调色、语义色、主要表面/描边、圆角、正文字号与字重 |
| `src/renderer/src/App.tsx` | 只在有**内联颜色/渐变**的地方同步（如进度环、电量环的 stroke 色）；不改结构、不改组件 |
| `docs/facts/视觉设计规范.md` | 同步新的色彩/圆角/字号规则 |

**不动的**：布局结构、组件划分、窗口尺寸、切页逻辑、动画时长与曲线、图标形状。

## 三、预期行为

1. 功能、尺寸、交互、动效与改动前完全一致；只有颜色、字重、圆角、间距的观感变化。
2. 五个展开页 + 收起胶囊 + 横幅/浮层都在新皮肤下保持可读：正文对比度不低于 4.5:1（深底浅字），次要信息不低于 3:1。
3. 语义色仍能区分：成功/正常、信息、警告、错误各一种，不混用。
4. 不引入外部字体、不引入 CSS 框架、不改 `zoom: 0.75`。

## 四、必要依赖

无。

## 五、验收条件

- A1 `npm run typecheck`、`npm run build` 通过。
- A2 五个展开页 + 收起态各截一张图，与改动前并排对比，逐条对照本文第一节六个问题：纯黑→带色深灰、紫→蓝、层次靠亮度、圆角收敛、字号上调。
- A3 对比度抽检：主文字、次要文字、辅助文字各一组，用工具算出实际比值并记录。
- A4 回归：`e2e-head-order`、`e2e-collapse-order`、`e2e-todo-today`、`e2e-schedule-day`、`e2e-bell-notify`、`e2e-shelf-view-pref`、`e2e-banner-fit`、`e2e-code-hint`、`perf-click-latency`。
- A5 用户在自己机器上看过并认可方向（审美属主观，最终由用户判定）。

## 六、不做什么

- 不做组件网格、不做统一面板尺寸、不改切页结构（第二步）。
- 不改动效时长/曲线、不改窗口尺寸、不改任何交互逻辑。
- 不引外部字体、不做真实背景模糊/液态玻璃折射（Windows 透明置顶窗上会掉帧，项目已有实测教训）；只做「伪玻璃」：半透明深色 + 内高光边。
- 不动置物架页的结构（用户明说这次先不管），但它的颜色跟着 token 一起换。
- 不合并回 `main`、不发版（等用户看效果）。

### 7.4 已知取舍

- 五页共用同一强调色，页面身份改由图标形状区分；若用户觉得「分不出页」，这里可以退回按页分色（改 `App.tsx` PAGE_META 五处）。

- 没有做真实 `backdrop-filter` 模糊：透明置顶窗上会掉帧，只做「半透明深色 + 内高光」的伪玻璃。
