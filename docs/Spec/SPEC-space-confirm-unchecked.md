# SPEC：默认不勾选的清理项加二次确认

日期：2026-11-20　分支：`space-merge-junk`

## 1. 目标

「空间」页里默认不勾选的项（诊断日志、回收站）一旦被用户勾上，点一次「清理选中项」就会直接永久删除，没有第二次确认。给这两项加一道确认：第一次点击只提示，第二次点击才执行。

## 2. 修改范围

- `src/renderer/src/settings/SpaceSection.tsx`
  - `CleanupPanel`（灵动岛组）：识别 `defaultChecked === false` 的已选项。
  - `JunkPanel`（系统组）：同上，覆盖回收站。
- 文档：`docs/facts/功能清单.md` 空间页对应小节、`docs/状态.md` 一句话状态。

不改主进程、不改清理逻辑、不改 IPC。

## 3. 预期行为

1. 已选项里**没有**默认未勾选项时：行为不变，点一次「清理选中项」直接执行。
2. 已选项里**有**默认未勾选项时：
   - 第一次点「清理选中项」：不执行任何删除，提示写明是哪几项、删除后不能恢复，按钮变成「确认清理」。
   - 再点「确认清理」：按原流程执行。
3. 以下任一情况使确认作废，按钮回到「清理选中项」：
   - 勾选状态发生变化（勾上/取消任何一项）；
   - 重新读取/重新计算；
   - 清理已经执行。
4. 系统组的提权项不额外加确认：UAC 本身就是系统的二次确认。
5. 卸载残留不套用：清理一律进备份、可撤销，已有「删除备份」的二次确认。

## 4. 必要依赖

无。

## 5. 验收条件

1. `npm run typecheck`、`npm run build` 通过。
2. 隔离实例（假 userData）：勾选「诊断日志」后第一次点清理，`startup.log` 仍在、提示出现、按钮为「确认清理」；再点一次才删除。
3. 勾选「回收站」同理：第一次点击不触发清空。
4. 只勾默认项（如临时文件）时仍一次点击执行。
5. 勾上默认未选项后再改动勾选，需要重新确认。

## 6. 不做什么

- 不做弹窗/模态框，沿用页面现有的「按两下」确认样式（与「删除备份」一致）。
- 不加「以后不再提示」开关。
- 不改默认勾选状态本身。
