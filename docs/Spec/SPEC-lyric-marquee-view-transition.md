# SPEC：歌词长句横向滚动 + 歌词页返回主界面动画

- 日期：2026-11-28
- 分支：`lyric-marquee-view-transition`
- 关联：SPEC-music-layout-2、SPEC-collapsed-lyric-bar、SPEC-island-widget-grid

## 1. 目标

1. **长歌词不再看不到**：歌词页（`词` 打开的右栏）和收起态歌词条里，一句太长会被裁掉。
   给超宽的那一句加「缓慢左右往返」的横向滚动，让整句都能读到；不超宽就保持静止。
2. **两个尺寸跳变都改成平滑过渡，且不闪、不裁**：
   - 歌词页（402×269）→ 组件网格（255×272）：旧版窗口/岛一帧缩到 255，内容靠非等比缩放补，
     网格被拉宽压扁又被窗口裁。现在窗口用小步补间（每 16ms 一次 `setBounds`）收窄，岛用
     rAF 逐帧收到 255，网格内容做 0.95→1 缩放 + 0.45→1 淡入。
   - 音乐页点「词」（255×219 ⇄ 402×269）：旧版是窗口宽度一帧跳过去，留下旧表面一帧「残影」
     （手机上录下来像两个岛）。现在窗口宽度也用小步补间，每帧只移动几 px，岛逐帧跟随。
   两个过程岛每帧都被钳在窗口内（`innerWidth/innerHeight`），任何一帧都不会溢出窗口。

## 2. 修改范围

- `src/main/index.ts`

    变高时先把窗口高度一步到位（避免底部内容被裁），只补间宽/位置。新增 `stopMorph()`，
    `animateTo` / `applyBoundsNow` 先停掉它；底图抓屏的「最近 1s 改过窗口尺寸」闸门把
    `morphTimer` 也算进去。
  - 新 IPC `island:set-expanded-size-animated`：与 `island:set-expanded-size` 同样收窄尺寸并记
    `expandedSize`，但展开态改用 `morphBoundsTo(computeBounds(true), ms)`。
- `src/preload/index.ts`
  - 新增 `morphExpandedSize(w, h, ms)`。
- `src/renderer/src/App.tsx`
  - 新增通用组件 `MarqueeText`（量溢出 → 设置位移/时长 → 往返动画）。
  - 歌词页每一行改用它（当前句自动滚；鼠标悬停某一行也滚；其余行右缘渐隐提示还有内容）。
  - 收起态歌词条 `.cl-text` 改用它（始终自动滚）。
  - `morphIslandSize` 改为 rAF 驱动的岛宽高补间：先量起点/终点，钉住起点尺寸，通知主进程

## 3. 预期行为

### 歌词横向滚动

- 当前句宽度超过歌词栏 → 先停 0.8s 展示句首，再匀速左移露出句尾，停 0.8s 后原路返回，无限循环。
  速度约 26 布局 px/s，单程 5~18s（越长越慢也越久）。
- 非当前句：不自动滚；鼠标悬停该行时滚（能点的行本来就有悬停反馈）。
- 不超宽的行：完全静止，不产生动画。
- 切句、开合歌词栏、改窗口尺寸后重新测量；不再溢出就恢复静止。
- 收起态歌词条：当前句超宽时同样往返滚动；换句后从头开始。
- 动画只用 `transform`，不触发逐帧布局。

### 歌词页返回主界面

- 从歌词页（`词` 已展开）点返回 → 岛宽从 402 用 ~320ms 收到 255，窗口用小步补间同步收窄
  （每帧几 px，不是一帧跳 147px），岛每帧都被钳在窗口内。
- 网格内容用 320ms 从 `scale(0.95)/opacity 0.45` 过渡到 `scale(1)/opacity 1`，「收拢 + 淡入」，
  不再是看不出动画的瞬切。
- 其它入口（普通功能页 → 网格、网格 → 功能页）保持原来的非等比 FLIP，不改手感。

### 音乐页「词」开合

- 打开：窗口用小步补间从 255 宽撑到 402（~200ms），岛宽同步补间，右栏歌词随岛的右沿逐帧露出；
  左栏随岛中心左移。
- 关闭：窗口/岛宽 402→255、高 269→219 一起补间（~220ms），回到无歌词栏布局。
- 补间期间所有尺寸上报暂停，结束后只上报一次最终尺寸；任何一帧岛都不超出窗口。

## 4. 必要依赖

无新增依赖。用浏览器原生 ResizeObserver / requestAnimationFrame / CSS animation，加 Electron
`setBounds` 定时器补间。

## 5. 验收条件

1. 探针：长句（`scrollWidth - clientWidth > 2`）的当前行存在 `mq-overflow` 且 `--mq-shift` 为负值；
   短句行没有 `mq-overflow`。
2. 探针：收起态歌词条对长句同样带 `mq-overflow`。
3. 探针：词开/词关/歌词页返回网格，岛宽都在约 200~320ms 内逐帧变化（不是一帧跳变），
   且**每一帧**岛宽高都不超过 `innerWidth/innerHeight`（clip 帧数 = 0）。
4. 手动：长句能完整看全；返回动画能看出「收拢 + 淡入」；动画期间无整屏闪白/闪烁、无残影双岛。
5. `npm run typecheck`、`npm run build` 通过；相关 e2e（音乐页、收起歌词条、页面切换）通过，
   遗留失败项需确认是环境性。

## 6. 不做什么

- 不把歌词滚动做成逐字卡拉 OK 高亮，不加纵向手动拖动。
- 不改歌词行点击跳转、滚动居中、缓存与抓取逻辑。
- 不把非歌词页面的缩放动画一并改掉；不改其它页面的窗口时序。
- 不做真正的「跨窗口尺寸的 GPU 缩放缓动」（Electron 透明窗口做不到逐帧改变合成层缩放），
  只把每帧窗口位移压到几 px，避免一帧大跳留下的旧表面残影。
