# SPEC：歌词长句横向滚动 + 歌词页返回主界面动画

- 日期：2026-11-28
- 分支：`lyric-marquee-view-transition`
- 关联：SPEC-music-layout-2、SPEC-collapsed-lyric-bar、SPEC-island-widget-grid

## 1. 目标

1. **长歌词不再看不到**：歌词页（`词` 打开的右栏）和收起态歌词条里，一句太长会被裁掉。
   给超宽的那一句加「缓慢左右往返」的横向滚动，让整句都能读到；不超宽就保持静止。
2. **两个尺寸跳变都改成岛本体的形状补间**：
   - 歌词页（402×269）→ 组件网格（255×272）：旧版是窗口/岛一帧缩到 255，内容靠非等比缩放
     （实测 `sx≈1.64 / sy≈0.91`）补，网格被拉宽压扁又被窗口裁。现在岛本身用 220ms 收窄，
     网格内容只做淡入。
   - 音乐页点「词」（255×219 ⇄ 402×269）：旧版是宽度一帧跳过去。现在岛宽 220ms 补间，
     歌词栏随岛变宽逐帧露出（关闭时反向收回）。
   两个过程都先把窗口撑到「起点/终点」的并集，岛在大窗口里变形；缩小时等岛收完才落窗口，
   所以任何一帧都不会被窗口裁，也看不到窗口尺寸跳变。

## 2. 修改范围

- `src/renderer/src/App.tsx`
  - 新增通用组件 `MarqueeText`（量溢出 → 设置位移/时长 → 往返动画）。
  - 歌词页每一行改用它（当前句自动滚；鼠标悬停某一行也滚；其余行右缘渐隐提示还有内容）。
  - 收起态歌词条 `.cl-text` 改用它（始终自动滚）。
  - 新增 `morphIslandSize`：用 WAAPI 补间 `.island` 的宽/高，窗口先撑到并集，期间
    `islandMorphRef` 拦住 ResizeObserver 上报，结束后再落最终窗口尺寸。
  - 点「词」的处理函数同步记下旧尺寸；`[lyricPanelOpen]` layout effect 在同一帧把岛钉回旧尺寸
    再补间。`backToGrid` 记下「来自展开的歌词面板」与岛当前尺寸；`[view]` effect 走
    岛收窄 + 网格淡入，不再做非等比/等比内容缩放。
  - 回到网格的尺寸上报 effect 在该路径跳过立即上报（否则窗口会先缩到 255 再被撑回，闪一帧裁切）。

  - 新增 `.mq` / `.mq-inner` / `@keyframes mq-scroll`。
  - 行内溢出但未播放时用右缘渐隐替代省略号。
- `docs/facts/功能清单.md`、`docs/facts/视觉设计规范.md`、`docs/状态.md` 同步行为。
- 不动歌词来源、缓存格式、滚动居中逻辑、其它页面的缩放动画；主进程不改。

## 3. 预期行为

### 歌词横向滚动

- 当前句宽度超过歌词栏 → 先停 0.8s 展示句首，再匀速左移露出句尾，停 0.8s 后原路返回，无限循环。
  速度约 26 布局 px/s，单程 5~18s（越长越慢也越久）。
- 非当前句：不自动滚；鼠标悬停该行时滚（能点的行本来就有悬停反馈）。
- 不超宽的行：完全静止，不产生动画。
- 切句、开合歌词栏、改窗口尺寸后重新测量；不再溢出就恢复静止。
- 收起态歌词条：当前句超宽时同样往返滚动；换句后从头开始。
- 动画只用 `transform`，不触发逐帧布局。

### 歌词页返回主界面

- 从歌词页（`词` 已展开）点返回 → 岛宽从 402 用 220ms 收到 255（高 269→272 一步到位），
  窗口先保持 402 宽（高度撑到 272），岛收完才把窗口落到 255×272。
- 组件网格保持终态排版，只做 220ms 淡入（0.25→1），不再缩放变形。
- 岛在自己的补间里居中收缩，落窗口前后岛在屏幕上的位置完全不变，看不到窗口跳变。
- 其它入口（普通功能页 → 网格、网格 → 功能页）保持原来的非等比 FLIP，不改手感。

### 音乐页「词」开合

- 打开：音乐页高度先一步到位（内容按终态排版，底部控件不会被裁），窗口宽度立即撑到 402，
  岛宽 220ms 从 255 补间到 402，右栏歌词随岛的右沿逐帧露出；左栏随岛中心左移。
- 关闭：岛宽 402→255、高 269→219 一起补间（先缩岛、最后才缩窗口），回到无歌词栏布局。
- 补间期间所有尺寸上报暂停，结束后只上报一次最终尺寸。
- 打开时高度不做补间（变高时钉旧高度会把播放键裁掉一截，探针帧实测过）。

## 4. 必要依赖

无新增依赖。用浏览器原生 ResizeObserver / Web Animations API / CSS animation。

## 5. 验收条件

1. 探针：长句（`scrollWidth - clientWidth > 2`）的当前行存在 `mq-overflow` 且 `--mq-shift` 为负值；
   短句行没有 `mq-overflow`。
2. 探针：收起态歌词条对长句同样带 `mq-overflow`。
3. 探针：词开/词关/歌词页返回网格，岛宽都在约 200~220ms 内逐帧变化（不是一帧跳变）；
   窗口宽度只在补间开始前（变大）或结束后（变小）变化一次，且变化时岛宽已经等于新窗口宽。
4. 手动：长句能完整看全；返回动画不变形；动画期间帧间隔无 >40ms 的卡顿（沿用现有帧探针）。
5. `npm run typecheck`、`npm run build` 通过；相关 e2e（音乐页、收起歌词条、页面切换）通过。

## 6. 不做什么

- 不把岛尺寸补间做进主进程的窗口补间；窗口仍走一次性 `setBounds`，只做「先撑并集、后落终值」的两次跳变。
- 不加纵向手动拖动歌词、不做卡拉 OK 逐字高亮。
- 不改歌词行点击跳转、滚动居中、缓存与抓取逻辑。
- 不把非歌词页面的缩放动画一并改掉；不改其它页面的窗口时序。
