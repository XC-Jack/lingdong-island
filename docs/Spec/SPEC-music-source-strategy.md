# SPEC-music-source-strategy：音乐页识别策略（自动选源 / 记住播放器 / 锁定）

- 建立日期：2026-11-19
- 对应基线提交：`d5a6cd1`（main，0.1.15 本地构建）
- 任务分支：`music-source`
- 用户背景：朋友「网易云 + 剪映」误显示剪映（已用黑名单临时修掉）；用户随后提出「媒体选择 / 锁定播放器」，并要求连识别策略一起做（2026-11-19：「识别策略可以做，锁定播放页也做，然后媒体选择也做」）。

## 一、目标

1. 自动模式不再让「陌生应用」抢走播放器：OBS、剪映这类只挂音频会话的软件永远不会被自动选中。
2. 多个**已知播放器**并存时，优先正在出声的那个；都暂停时保持「上次认过的那个」，不来回跳。
3. 提供锁定基础：记住用户手动选的音源（`prefs.musicSourcePin`），锁定期间只显示它。
4. 为选择器提供数据：桥接每次状态回包里带上当前所有候选音源（exe、显示名、是否在播）。

## 二、修改范围

| 文件 | 改动 |
|---|---|
| `src/main/smtcScript.ts` | ①`GetFallback` 增加「已知播放器」白名单门禁：非白名单 exe 只有在**正在出声且标题像歌名**时才可进入候选，且不覆盖仍存活的「上次播放器」；②状态回包增加 `sources` 数组（所有候选，含被门禁挡下的，供选择器展示）；③新增 `{"cmd":"focus","value":"<exe>\|"}`：锁定后只跟踪该 exe 的标题/进度条/音量，空值回自动 |
| `src/main/musicStore.ts` | `MusicState` 增加 `sources` / `pinnedExe` / `pinnedMissing`；`recompute()` 处理锁定优先级（锁网易云时 CDP 恒优先，不再看 `playing`）；`applyControl()` 在锁定非网易云时把命令路由到该 exe；锁定的应用不在运行时返回空态而不是回落自动 |
| `src/main/prefsStore.ts` | 新增 `musicSourcePin?: string`（小写 exe 名，空/缺省＝自动），带校验与白名单无关（任何 exe 都可锁） |
| `src/preload/index.ts` | 暴露 `musicSetSource(exe \| null)`（走 IPC `music:set-source`） |
| `docs/Spec/SPEC-music-source-strategy.md` | 本 SPEC |

**不动**：SMTC 主路径选会话、网易云 CDP 的开启逻辑、渲染层 UI（选择器另立 `SPEC-music-source-picker`）。

## 三、预期行为

1. **陌生应用永不自动选中**：`obs*`、`jianyingpro`、`capcut` 继续走黑名单；其余不在「已知播放器」表里、又没有用户在列表里点选过的 exe，最多出现在 `sources` 里供选择，不会被 `recompute()` 当成当前音源。
2. **已知播放器**（初始表：`cloudmusic`、`qqmusic`、`kugou`、`kuwo`、`spotify`、`potplayermini64`、`potplayermini`、`foobar2000`；可随实测补充）：多个并存时优先 `state=1`（正在出声）；都在暂停则保留上次认过的；进程退出后回到空态或其它在播播放器。
3. **锁定**：用户选定某 exe 后，无论其它应用在播与否，只显示它：
   - 锁网易云：CDP 可用就用 CDP（暂停也显示暂停态）；CDP 不可用则用桥接记忆/窗口标题。
   - 锁其它播放器：桥接 `focus` 到该 exe，标题、进度条、音量都只读它。
   - 锁定应用退出：`active=false` + `pinnedExe` 保留 + `pinnedMissing=true`，**不自动切到别的应用**；选择器里提供「自动」解锁。
4. **自动**：`musicSourcePin` 清空后立即回到第 1、2 条规则。
5. 设置不跨机器同步，只存本机 `prefs.json`。

## 四、必要依赖

无新增依赖；沿用桥接行协议，新增字段属于向后兼容扩展（旧渲染层忽略即可）。

## 五、验收条件

- [ ] `npm run typecheck`、`npm run build` EXIT=0。
- [ ] 桥接 `poll` 回包含 `sources`，且 `sources` 列出当前有音频会话的应用（含被门禁挡下的 OBS/剪映）。
- [ ] 复现脚本：起一个非白名单、标题带 ` - ` 的音频会话进程，同时让白名单播放器保持「进程在、暂停」：自动模式下当前音源仍是白名单播放器。
- [ ] 只开非白名单播放器（无其它播放器）：自动模式下不会被当成当前音源（选择器里可选）。
- [ ] `music:set-source` 锁到非网易云播放器后，上一首/播放/下一首命令作用在该 exe（桥接 ack 的 `exe` 与锁定值一致）。
- [ ] 锁定的 exe 退出后：`active=false`、`pinnedMissing=true`，不会切到其它正在播的应用。
- [ ] 清空锁定后恢复正常自动选源。
- [ ] `node scripts/e2e-music.mjs` 与改动前基线一致（记录失败项，不掩盖）。

## 六、不做什么

- 不做「所有播放器的通用识别」：白名单不是穷举，未收录的靠用户在选择器里点选（点选即锁定）。
- 不按窗口标题做黑名单/白名单判断，只做候选门禁，避免误伤。
- 不改网易云 CDP 自动开启、桌面歌词、音量控制通道。
- 不改渲染层（选择器 UI 在另一份 SPEC）。
