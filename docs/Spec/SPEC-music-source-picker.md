# SPEC-music-source-picker：音乐页「音源」入口与选择器

- 建立日期：2026-11-19
- 对应基线提交：`d5a6cd1`（main，0.1.15 本地构建）
- 前置 SPEC：`docs/Spec/SPEC-music-source-strategy.md`（提供 `sources` / `pinnedExe` / `pinnedMissing` 与 `music:set-source`）
- 用户决定（2026-11-19）：UI 落点选方案 A —— 放在页面头部第一行右侧的胶囊，点开右对齐浮层（草图见本轮会话；临时截图已删）。

## 一、目标

1. 音乐页头部右侧显示当前音源胶囊：`音源 · 网易云音乐 ▼`（未锁定时），锁定时显示锁标记。
2. 点开显示当前在跑的媒体应用列表，第一项是「自动（跟随播放）」；点一项即选中并锁定，点「自动」解除锁定。
3. 锁定应用未运行时，胶囊与列表都明确显示「未运行」，不误导、不自动换源。
4. 选择器只做「选谁」，不新增播放控制命令。

## 三、预期行为

1. **胶囊**：只在音乐页显示，位于 `head-top` 右侧（今天音乐页该位置为空）。文案 `音源 · <显示名> ▼`；自动模式显示当前音源；锁定后加小锁标记（Segoe Fluent Icons `U+E72E`）并保留显示名。
2. **浮层**：右对齐到胶囊下沿，宽约 172 视觉 px；条目顺序：
   - `自动（跟随播放）`（右侧「推荐」）
   - 在跑的媒体应用，在播的排在暂停前面；每项右侧「● 在播」/「暂停」
   - 当前音源有底色；锁定项有勾
   - 锁定应用未运行：该项显示「未运行」，仍可点「自动」解除
3. 底部灰字说明：`选中后固定显示，选「自动」恢复跟随`。
4. 关闭时机：再次点胶囊、点击浮层外、`Esc`、切到其它页、岛收起。
5. 浮层打开不触发岛收起（点击事件不冒泡到岛的手势），也不因鼠标移出面板而关闭。
6. 列表最多 5 项可见，超出滚动；没有其它应用时只显示「自动」。
7. 数据为空（桥接未启动 / 读不到）：胶囊显示「音源 · 自动」，浮层只有「自动」与一行灰字「没有检测到其它播放器」。

## 四、必要依赖

无新增依赖；使用 `state.sources` 与 `musicSetSource`（见策略 SPEC）。

## 五、验收条件

- [ ] `npm run typecheck`、`npm run build` EXIT=0。
- [ ] 只有音乐页显示胶囊；其它页头部右侧仍为空。
- [ ] 点胶囊打开浮层、再次点击/Esc/点外部关闭；打开时岛不收起。
- [ ] 列表项与主进程 `sources` 一致（名称、在播/暂停、当前项高亮）。
- [ ] 点「汽水音乐」→ 胶囊变「音源 · 汽水音乐 🔒」，主进程 `pinnedExe` 写入 `prefs.json`；刷新窗口后仍保持锁定。
- [ ] 点「自动」→ 清除锁定，胶囊恢复到自动识别结果。
- [ ] 锁定的应用退出 → 胶囊显示「未运行」，音乐区为空态，不切到别的应用。
- [ ] `node scripts/e2e-music.mjs` 结果与改动前基线一致（失败项照实记录）。
- [ ] 用户在真实「网易云 + 汽水」场景确认切换手感。

## 六、不做什么

- 不做完整媒体库或安装应用列表：只列当前有音频会话/SMTC 的应用。
- 不做「每个应用单独音量/歌词」，不做设置页常驻入口。
- 不改收起态，不新增快捷键。
