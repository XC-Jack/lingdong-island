# SPEC：点岛后全屏避让失效（修「最大化/全屏时岛还留在屏幕上」）

- **建立日期**：2026-11-25
- **基线提交**：`747bfa6`（main，v0.5.1 发版后）
- **任务分支**：`fix-avoid-self-foreground`
- **关联**：`../facts/功能清单.md` 第 14 条（US-041 全屏自动避让）、`SPEC-avoid-mode-and-latency.md`、`SPEC-avoid-show-attribution.md`、`SPEC-no-reveal-in-fullscreen.md`

## 一、目标

修掉用户 2026-11-25 用手机翻拍另一台电脑反馈的现象：「全屏或窗口最大化了，岛依然会显示」。

**真因（本机已复现）**：避让判定只看**前台窗口**。用户点一下岛，岛自己的窗口就成了前台窗口；C# 探针对「本进程的窗口」直接返回 `N`（不是全屏应用），状态机据此认为「退出全屏了」，把岛放回来并清掉临时现身状态。之后鼠标移开也不会再藏，要等用户点回浏览器才会重新判定。

复现记录（`.tmp/probe-avoid-self-focus.mjs`，本机 1536×960 逻辑分辨率）：

| 步骤 | 判定码 | 岛可见 |
|---|---|---|
| 最大化窗口置前 | `Z` | 否 |
| 光标摸屏幕顶边唤回 | `Z` | 是 |
| 把岛窗口抢到前台（等价点击岛） | `N` | 是 |
| 光标移到 (400,500) | `N` | **是（应为否）** |

同时修掉顺带暴露的一个视觉缺陷：摸边唤回时胶囊上会闪一条**没有样式**的白底黑字「已让路 · 移开鼠标自动隐藏」。原因是该提示只在「窗口已隐藏、渲染层还认为避让中」的竞态窗口里可见，全仓库没有对应 CSS 规则；它从来没有过稳定的可见态。

## 二、修改范围

| 文件 | 改动 |
|---|---|
| `src/main/fullscreenWatch.ts` | `probeCs()`：前台窗口属于本进程时，不再直接判 `N`，改为沿 Z 序（`GetWindow(h, GW_HWNDNEXT)`）找**第一个非本进程、可见、未被 DWM cloak、非壳层**的窗口作为判据；找不到才 `N`。新增 `GetWindow` 的 P/Invoke 声明；文件头注释补这条规则 |
| `src/renderer/src/App.tsx` | 删除 `avoid-tip` 提示条（只有 JSX、零 CSS、只在竞态帧可见；`avoidHidden` 状态保留，它仍用于暂停抓屏底图） |
| `docs/facts/功能清单.md` | 第 14 条补「前台是本进程窗口时按 Z 序往下取判据」的规则 |
| `docs/状态.md` | 一句话状态 + 本轮段落 |

**明确不改**：
- 三档策略（`maximized` / `fullscreen` / `off`）、150 ms 去抖、1.2 s 现身稳定期、摸边唤回口径与 `revealArmed` 闩锁；
- 手动隐藏（`manual`）、托盘恢复、横幅临时现身（`bannerHold`）；
- 常驻辅助进程 / 心跳文件 / 回退单发轮询的机制与节奏；
- 窗口定位、尺寸上报、开合与切页动画（用户同时提到的「位置偏移 / 显示不全」尚未复现，另开 SPEC 处理）。

## 三、预期行为

1. 前台是**最大化**窗口，用户摸顶边唤回岛并点击展开后：鼠标离开岛约 0.3 秒内岛自动隐藏（不再一直盖在标题栏上）。
2. 前台是**真全屏**应用时：行为不变——不自动唤回；若通过托盘/横幅出现，退出全屏或鼠标操作结束后按现有规则回隐。
3. 前台是**普通窗口 / 桌面 / 壳层窗口**时：岛照常可见，判定为 `N`，行为与现在完全一致。
4. 前台窗口属于本进程（岛、设置窗、岛仔）时：判定取 Z 序上第一个**其它应用**的窗口；该窗口最大化/真全屏则继续避让，普通窗口则照常显示。
5. 「已让路 · 移开鼠标自动隐藏」这条无样式提示条不再出现。

## 四、必要依赖

无新增 npm 依赖、无新增原生模块。仍是常驻 `powershell.exe` + 内嵌 C#，只多一个 `user32!GetWindow` 声明和一次最坏 24 步的 Z 序遍历（120 ms 一轮，成本可忽略）。

## 六、不做什么

- 不解决「位置偏移 / 显示不全」——该现象在这段视频里没有可判读的证据（最终展开面板居中、内容完整），需要用户补整屏录屏和那台电脑的版本号后再定。
- 不改「最大化算不算全屏」的产品语义，不改默认档位。
- 不为「前台是自己」单独加 `S` 状态码或新 IPC；只在 C# 探针内部换判据对象。
- 不动窗口位置 / 尺寸计算、不动渲染层布局。
