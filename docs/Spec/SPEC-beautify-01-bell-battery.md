# SPEC 美化-01 收起态通知铃铛 + 电量前移

## 一、目标

按用户 2026-11-08 拍板的两项收起态美化：
1. **通知提示换铃铛**：收起态的「未读通知红点」换成用户提供的铃铛设计——白色铃铛 + 右上角红色小圆点（新通知时显示），参考用户贴图（黑色圆角底、白铃铛、红点在右上）。
2. **电量前移**：收起态组件顺序调整，电量环放到岛仔（宠物）前面。

同时把 boardui.com 美化灵感清单记录在案（本轮不做，见第六节）。

## 二、修改范围

- `src/renderer/src/App.tsx`：收起态分支——新增 `IcoBell` 铃铛图标组件；`collapsed-dot` 红点改为铃铛+红点徽标；组件顺序把电量环移到 `<Pet />` 之前。
- `src/renderer/src/styles.css`：`.collapsed-bell`（铃铛容器）与 `.bell-badge`（右上红点）样式；删除或保留 `.collapsed-dot` 视实现而定。
- `scripts/e2e-collapse-beautify.mjs`（新建）：断言铃铛渲染与电量顺序。
- 不改：展开态任何内容；通知页本身；横幅；数据层；其它收起态组件（时钟/网络/待办数）的顺序与样式。

## 三、预期行为

1. **铃铛**：有未读通知时，收起态右侧显示白色铃铛图标（描边风格，贴合深色胶囊底），铃铛右上角带红色小圆点（带轻微光晕）；无未读时不渲染（与原红点逻辑一致）。
2. **顺序**：收起态从左到右变为「电量环 → 岛仔 → 时钟 → 网络 → 待办数 → 铃铛」（原：岛仔 → 时钟 → 电量 → 网络 → 待办数 → 红点）。铃铛保持在最右（通知是最后被关注的信息）。
3. 鼠标悬停铃铛显示「N 条未读通知」提示；无障碍标签同原红点。
4. 各开关（页面管理 collapsed.*）行为不变：关掉电量的用户看不到电量环，关掉岛仔不显示岛仔，互不影响。

## 四、必要依赖

无新依赖。纯 SVG + CSS。
