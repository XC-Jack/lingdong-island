## 打包与安装固定流程

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npm run dist
# 静默安装。注意：/S 不会复用上次选的目录，默认落到
# %LOCALAPPDATA%\Programs\lingdong-island；要装到指定目录必须用 /D=（放最后）
Start-Process -FilePath "release\灵动岛 Setup 0.1.0.exe" -ArgumentList '/S','/D=D:\软件\灵动岛' -Wait
# 启动验证（必须先清环境变量，否则 exe 秒退）
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
Start-Process 'D:\软件\灵动岛\灵动岛.exe'
Get-Process 灵动岛
```
