## 五、踩过的坑（美化类任务最可能再遇到）

- **跑 e2e 前先清进程**：`Get-Process electron -ErrorAction SilentlyContinue | Stop-Process -Force`。残留进程会污染基于进程枚举的 Win32 断言（曾让 fullscreen-avoid 假败 4/7，清完 7/7）。
- **e2e 起 electron 必须删 `ELECTRON_RUN_AS_NODE`**：用 `node spawn` + `delete env.ELECTRON_RUN_AS_NODE`，不要用 pwsh 直接起。
- **e2e 的 userData 路径是 `%APPDATA%\lingdong-island`**（`process.env.APPDATA`），不是 `homedir()`——DSH 宿主下 `homedir()` 返回 D 盘，Electron 实际在 C 盘。
- **CDP 的 `Runtime.evaluate` 查异步值必须带 `awaitPromise: true`**，否则 `.then()` 链返回 `{}`。
- **pwsh 内联 `node -e` 里的复杂模板串 / `$` 变量会被宿主转义损坏**——写 `.mjs` / `.cjs` 文件跑。
- **改 UI 后 e2e 里别乱点 `.island`**：reload 后岛本来就是收起态，点一下会展开，收起态组件全卸载导致断言查空。
- **`npx asar extract-file` 对 `out/main/index.js` 会报 not found**，要验证打包内容用整包 `npx asar extract`。
- 造未读测试数据要**同时清 `lastOrder` 和 `hiddenUntil`**（`%APPDATA%\lingdong-island\notif-read.json`），只清一个仍为 0。
