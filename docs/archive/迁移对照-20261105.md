## 五、对博主模板的三处偏离（有意为之，均已在此说明）

| 模板要求 | 本仓库实际 | 理由 |
|---|---|---|
| `src/.git/` 独立仓库 | `src/` 是普通目录，仓库在项目根 | 本仓库**先有代码再有框架**，53 个跟踪文件 + 67 次提交 + 11 个标签都在根仓库，拆分会丢历史。用户已确认「复用职责相同的文件」优先 |
| 里程碑放 `docs/Spec/milestones.md` | 放 `docs/facts/里程碑.md` | 里程碑是长期产品事实，不是单次任务规格；放 Spec 里会被当成可替换文件 |
| 模板无「当前状态」与「版本回溯索引」 | 新增 `docs/状态.md` + `docs/facts/版本历史.md` | 这两块是本项目已经在用的刚需（原 `开工交接.md` / `版本记录.md` 承担），删了会丢功能 |
| 模板要求「远端仓库按授权配置」 | 当前无远端，如实记录 | 用户未提供地址，不自行创建、不声称已同步 |
