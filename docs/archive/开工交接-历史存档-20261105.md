## 坑位备忘

- 屏幕缩放 125%，物理 1920×1200 逻辑 1536×960。定位一律按逻辑像素。
- 鼠标穿透：**已决策不做**（整窗穿透会让胶囊点不开；窗口小，透明区仅四角）。若将来精修用原生 WS_EX_TRANSPARENT 分区域方案。
- Windows 11 可能自动圆角裁剪，需显式关闭。（实测透明窗口下未观察到裁切，仍留此条。）
- 没有 VS 原生工具链，别选需要 C++ 编译的依赖。
- DSH 环境有 `ELECTRON_RUN_AS_NODE=1`，脚本里跑 electron 前先清掉；electron postinstall 可能不跑，手动 `node node_modules/electron/install.js`。
- electron 下载走 `$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'`。
- **`npm run dist` 报 `unable to verify the first certificate`**：electron-builder 直连 GitHub 拿二进制被证书拦。打包前同时设 `$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'` 和 `$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'` 再跑即可（第十七轮实测有效）。
- 自动化测试用 CDP：`node scripts/e2e-m1.mjs` / `e2e-m3.mjs` / `e2e-m4.mjs` / `e2e-m4-drop.mjs` / `e2e-reorder.mjs` / `e2e-notify.mjs` / `e2e-schedule.mjs`（自带启动+清理）。**SendKeys 模拟键盘不可靠**，别用。**CDP 端口用 9321**（9222/9223/9230 会被残留实例或 DSH 宿主占用）。打包版无 CDP（安全行为，UI 自动化只对开发版可用）。
- 验证码功能已按用户场景移除（用户验证码从不经过电脑），`captchaStore.ts` 已删；版本记录 m5 行保留了历史说明。
- 通知页读 `%LOCALAPPDATA%\Microsoft\Windows\Notifications\wpndatabase.db`（复制 db+wal+shm 三件套后 node:sqlite 只读；大整数列必须 `CAST AS TEXT`；FILETIME→ms：`Number(t)/10000 - 11644473600000`）。真实通知到达场景用户未验证，等自然验证。
- 日程提醒：`scheduleStore.ts` 每 60s 检查，`time<=当前HH:mm` 且未 reminded → Electron Notification；过期未完成徽标橙色。
- asar 内 `__dirname` 指向 `resources\app.asar\out\main`——打包版自启 args 走 `app.isPackaged` 分支只带 `--hidden`，开发版才补 app 路径。开机自启 Run 键：`electron.app.灵动岛 = "D:\软件\灵动岛\灵动岛.exe" --hidden`。
- 拖放链路测试：`e2e-m4-drop.mjs` 验证 shelfAdd→广播→UI 即时刷新→不白屏；`e2e-reorder.mjs` 用合成 DragEvent 驱动真实处理器链验证连续换位。
- **格子拖动处理器必须区分内部/外部拖放**：置物架格子 onDragOver/onDrop 只在 `reorderFrom.current !== null`（架内图标拖动）时 stopPropagation，否则外部文件拖到格子上被吞（🚫 光标、放不进去）。
- **onDragEnter 必须去重**：冒泡每划过一个子元素重复触发，反复 gotoPage 重挂页面重放动画 = 频闪抖动；dragActive ref 一次拖动只处理一次（dragleave/drop 复位）。
- **CDP 探针双解包**：Runtime.evaluate 结果取 `resp.result.result.value`（onmessage 存整个 d，ev() 里取 resp.result）；探针直调 window.island.shelfAdd() 不触发 UI 刷新（广播只在拖放路径），必须再调 emitShelfAdded(latest)。
- **头部布局**：状态区绝对居中后，panel-head-spacer 保持 flex:1 让右侧元素靠右——不要给右侧元素加 margin-left:auto（与 spacer 叠加会均分空间把元素推回中间）。
- 视图切换菜单/时间面板弹出层模式：state + absolute 浮层（.shelf-view-pop/.sched-time-pop）+ document mousedown contains 点外收起，可直接复用。
- **靠右/居中类布局必须在空态（最小内容）下验证**：`.page-fade` 无宽度约束时宽=内容自然宽，空置物架 210px、空通知 143px，工具条的 width:100% 只到这个宽度，按钮会悬在中间。当前修法：第 2/3 页加 `.page-fade.wide{width:100%}`（App.tsx 按 page===1||page===2 拼 className）。**不要**改成全局 `.page-fade{width:100%}`——日程页 `.sched-split` 靠 max-content 撑开，与 `.island` 的 max-content 互锁，会把日程页从 553 压到 420 裁掉内容（第五轮就是只在满宽态验证才出的错）。
- 电量圆环：r=15.5 周长 97.4，strokeDasharray=`${(battery/100)*97.4} 97.4` + rotate(-90 18 18) 从顶部起画；组件样式 .head-battery-ring 收起/展开共用。
- CDP 验证脚本模板在 `.tmp/verify-*.mjs`（batteryring/headoverlap/viewpop/shelfviews），起开发版 `electron.exe . --remote-debugging-port=9321` 后跑；e2e 端口同样 9321。
- CDP 旁路写数据不会刷新 React UI（`window.island.todosAdd()` 绕过 setState），视觉验证必须真人点。
- **启动打包版 exe 报「bad option: --hidden」/秒退**：是当前 shell 继承了 `ELECTRON_RUN_AS_NODE=1`（electron 被当纯 Node 解析参数），不是安装包问题。`Remove-Item Env:ELECTRON_RUN_AS_NODE` 后再启动；真人双击/开始菜单/开机自启均不受影响。
- 电量读取走 `spawnSync('powershell.exe', [... 'Get-CimInstance -ClassName Win32_Battery'])`（`src/main/statusStore.ts`），无桌面会话/无电池返回 null，UI 自动隐藏。
- 拖文件进窗口会触发 Chromium 导航跳转，已在 `src/main/index.ts` 用 `will-navigate` preventDefault 拦截；渲染层拿路径走 preload 的 `filePath()`（`webUtils.getPathForFile`，Electron 32+ 没有 `File.path`）。
- 系统图标：`shelfStore.ts` 的 `systemIconPng(ext, realPath)`，PowerShell 脚本缓存在 `userData\icon-cache\extract-icon.ps1`；改图标逻辑时删除 `icon-cache\*.png` 强制重新提取。
- 收起态拖入文件：主进程 `island:drag-hover` 放大窗口，渲染层 `onDragEnter` 切置物架页；落点在整岛根（`onDropRoot`），落盘后 `emitShelfAdded` 广播刷新面板。
