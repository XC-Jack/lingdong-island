# 产品定义

> 本文件负责唯一事实：「灵动岛」是什么、给谁用、边界在哪。其它文档引用本文件，不复制。

## 一句话定义

Windows 桌面屏幕顶部居中的悬浮胶囊（俗称「灵动岛」）：平时收起成一条窄条，点开变成面板，把常用信息收在一处，并养一只会表达情绪的小宠物「岛仔」。

## 用途

把日常高频查看的几件事从分散的窗口里收回到屏幕顶部一处，看一眼就有，不用切窗口：
- 还剩哪些待办（完成度一眼可见）
- 今天还有什么安排
- 系统通知有没有新的
- 手头临时要用的文件先搁一下（置物架）
- 电量、时间（收起态就有）

## 用户角色

**当前唯一角色：用户本人（单机单用户）。** 依据：本产品是个人桌面工具，无账号体系、无多用户场景，数据全部落在本机 `userData`。

> 角色梳理详见 `docs/facts/用户角色与用户故事.md`（按博主流程从头梳理，建立中）。

## 形态与交互基调

- 位置：屏幕顶部水平居中，留缝隙 `TOP_GAP = 6px`（`src/main/index.ts` 一处常量可改）。按主显示器工作区计算，不硬编码坐标。
- 收起态：窄条（当前实测 240×42 左右，宽度随内容自适应），显示时间、电量、岛仔、未读红点。
- 展开态：面板，多页切换（`‹ ›` 箭头 + 底部圆点），尺寸随内容自适应（视觉 min 225×113 / max 540×315；2026-11-16 起，此前是固定 353×240）。
- 岛仔：会呼吸、眨眼；被讨好（勾掉待办、拖文件进岛）时开心 1.8s（弯眼 + 星星 + 弹跳）。
- 视觉基调：深色/暗色，圆角胶囊，紫色为强调色。

## 需求来源与独立性

- 需求来自用户提供的一段 B 站演示视频（原作者作品，**无源码**）。本项目是独立重做，不复制原作者代码。
- 视频原件：`d:\Users\honor\Downloads\15期丨我给Windows做了个灵动岛，还养了个小家伙 之前_7703598614018329882.mp4`

## 明确不做

- 不做多用户、不做账号、不做云端同步（当前）。数据只在本机。
- 不做鼠标穿透（已决策：整窗穿透会让胶囊点不开，窗口小、透明区仅四角，收益极小）。
- 验证码识别功能已按用户实际场景移除（用户的验证码从不经过电脑）。
- 不修改同级其它项目目录。
