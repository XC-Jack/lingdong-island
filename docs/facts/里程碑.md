# 里程碑

> 本文件负责唯一事实：项目分几个阶段推进、每个阶段的目标与完成条件、当前推进到哪。
> 博主模板把里程碑放 `docs/Spec/`，本仓库改放 `docs/facts/` —— 理由：里程碑是**长期产品事实**，不是某一次任务的规格；放在 Spec 里会被当成可替换的任务文件。
> 格式沿用五要素：阶段目标 / 包含范围 / 前置条件 / 交付结果 / 完成条件。

## 当前状态

**M0–M4 全部完成（含 m5–m8 的额外功能），当前处于「用户实测反馈驱动的打磨阶段」。** 下一个新里程碑（M9 起）尚未确定，等产品讨论后规划。

## 已完成里程碑

### M0 岛壳 ✅

- **阶段目标**：跑通透明、置顶、圆角的悬浮窗口，能收起/展开。
- **包含范围**：主进程窗口创建、`animateTo` 尺寸动画、收起/展开状态机、圆角与阴影。
- **前置条件**：Electron 环境可跑（`npm start`）。
- **交付结果**：仓库首个可运行版本，标签 `prep-baseline-m0`。
- **完成条件**：[实测] 真机可见顶部胶囊；点击展开/移出收起正常。

### M1 待办清单 ✅

- **阶段目标**：第一页可用——记录待办并看到完成度。
- **包含范围**：`todoStore` 数据层、增/勾/删/改名、完成度 `n/m` 显示、持久化。
- **前置条件**：M0 完成。
- **交付结果**：标签 `m1-todos`，e2e `scripts/e2e-m1.mjs`。
- **完成条件**：[实测] e2e PASS；重启应用数据不丢。

### M2 岛仔 ✅

- **阶段目标**：宠物有情绪表达，让操作有反馈。
- **包含范围**：呼吸、眨眼、开心 1.8s（勾待办/拖文件触发）。
- **前置条件**：M1 完成（需要有可触发的动作）。
- **交付结果**：标签 `m2-pet`，e2e `e2e-m2.mjs`。
- **完成条件**：[实测] e2e PASS；真人能看到明显表情变化。

### M3 状态栏 ✅

- **阶段目标**：收起态就能看到关键系统状态。
- **包含范围**：电量读取（PowerShell CIM + 缓存 + 轮询）、收起态布局。
- **交付结果**：标签 `m3-status`，e2e `e2e-m3.mjs`。
- **完成条件**：[实测] e2e PASS；读数与实际电量一致。当时 Wi-Fi 未做（后续 US-005 已补、见 `docs/facts/功能清单.md` 第 5 节）；倒计时 US-006 已由用户否决不做（见 `docs/facts/用户角色与用户故事.md` 第五节），不是待办。

### M4 置物架 ✅

- **阶段目标**：文件能拖进来暂存，手边文件不用满桌面找。
- **包含范围**：拖放接收、去重、持久化、系统图标、四档视图、架内换位、清空确认。
- **交付结果**：标签 `m4-shelf` + `ux-shelf-polish` + 后续第十三~十五轮打磨。
- **完成条件**：[实测] e2e（m4 / m4-drop / reorder）PASS；[未验证] 真实鼠标拖拽。
