## 逐项说明

### 0. 整体尺寸与观感

- **岛整体按 0.75 等比缩小（SPEC-island-compact，2026-11-11）**：用户原话「各个界面整体比例小一点，迷你一点，就是我没见过就是灵动岛这么大的」。实现方式是 `styles.css` 里 `.app { zoom: 0.75 }` 一处生效，字号、图标、内边距、圆角全部跟着缩，不是只缩外框；主进程的窗口尺寸上下限同步按 0.75 收缩（收起态窗口高 66、展开态上限 540×315）。**实测**：收起态胶囊 142×31.5（原 42 高）、窗口 144×67。
- **各页尺寸统一固定、不随内容拉伸（2026-11-11 第二轮，用户要求）**：第二版把 `.island.expanded` 从「按内容撑开 + min/max 区间」改成**固定 440×252 布局 px**（0.75 缩放后视觉 353×240），五个页面全部同尺寸；加条目、切页都不再改变岛的大小，内容超出在列表内部滚动（实测待办 8 条时列表高 50、内容高 354）。日程页原来是 `width:max-content` 撑到 416（比别的页宽 100px），现在也压到 330（`.sched-split` 改 `width:100%`、`.cal` 宽 232→204、`.sched-day` min-width 252→168）。
- **翻页到头停住、不循环（2026-11-11 第二轮，用户要求）**：原来 5 页循环，「‹」连点会从第一页跳回最后一页。**真正的 bug 是删页面管理后残留的 `if (p === 4) return list[0]`**——page 4 当年是页面管理面板，搬进设置窗口后 4 变成音乐页，于是翻到音乐页就被弹回第一页。现已清掉该守卫和另一个 useEffect 里的 `if (p >= 4) return p` 豁免。
- **两个必须记住的实现坑**：①`zoom` 不能挂 `html`（会连视口 CSS 宽度一起缩，岛比视口宽 → 横向被裁），必须挂 `.app`；②`.app` 里不能写 `width: calc(100% / 0.75)`（`zoom` 元素的百分比已按缩放坐标系解析过，再除会宽一倍、岛跑到窗口右边被裁），写 `100%` 正好。

### 1. 待办清单（page 0）

- 这一页的定位是「今天要做什么」的速览：列表 = 所有待办 + **今天**的日程混排。明天的、昨天的日程都不出现在这里（要看别的日期去日程页）。
- 增加、勾选完成、删除、双击行内改名（空文本取消改名）。
- 完成度大号显示 `已完成数/总数`（如 `2/3`），这个总数把待办和今天的日程一起算。
- **完成度圆环 + 进度条（美化-04，2026-11-11）**：右上角那行数字左边加了一个 14px 的小圆环（底环 + 按完成比例顺时针填充的前景环，全做完时变实心绿带光晕），数字格式仍是 `n/m` 不变（两条 e2e 对它做精确字符串比对）；列表最下方多了一条横向进度条（细轨 + 圆头绿色填充 + 右侧「还差 N 件 + 百分比」，全做完时文案改「今天全部做完」）。两者都由同一份 `done/total` 驱动：圆环靠 SVG `stroke-dashoffset`、进度条靠 `transform: scaleX`，都用 320ms 缓动，切页时不跳。
- 勾选时 ✓ 有 `check-pop` 弹跳动画（180ms），触发岛仔开心。
- 加完一条后输入框保持焦点，可连续录入。
- 列表没有条数上限；内容超过岛高度上限后列表在岛内滚动（不显示滚动条），新加的一条会自动滚到底部进入视野（2026-11-05 修复，此前超长部分会溢出窗口被裁掉、看起来像「加不上」）。**2026-11-11 起岛高固定为 440×252 布局 px（视觉 353×240），不再按内容撑开**，所以条数一多就只在列表内滚。
- 在这一页加的内容存为**今天的日程**（不是待办）：今天在待办页和日程页都能看到，明天从待办页消失、仍留在日程页今天那一格。加的时候可以点右边的钟选一个时间，也可以不选。
- 列表里的日程条目：有时间的左侧显示 `09:00` 这样的时间徽标（只显示几点几分，不显示日期），过点还没完成的徽标变橙；可以直接勾选，勾选结果与日程页同步。
- 列表里的待办条目：与以前一样，没有时间徽标，双击可改名。
- 收起态就能看今天还剩几件：矮条最右侧（电量环右边、未读红点左边）只显示一个绿色数字 N（N = 待办 + 今天的日程里未完成的件数），不带图标。鼠标悬停提示「今天还有 N 件没做完（共 M 件）」。全部做完或一条都没有时这块不显示，不占地方。数字在「首次启动」和「每次从展开态收回」时各现算一次（不轮询），所以勾完一条收回就能看到数字减一。

### 2. 置物架（page 1）

- 拖入文件即暂存（整岛接收拖放），自动去重，持久化。
- 四种视图：大图标 84px / 中图标 64px / 小图标 48px / 列表；点击工具条按钮弹出菜单选择（不是循环切换）。
- 视图选择会记住（US-037 起）：选完写进主进程 `prefs.json` 的 `shelfView` 字段（经 `prefs:get`/`prefs:set` IPC），重启应用后仍是上次那个视图；从来没选过、或者值被改坏，都回落「大图标」，不报错。早期版本存渲染层 localStorage，跨重启会丢（见 US-037）。
- 图标视图横向胶片条，放不下时两侧出现 `‹ ›` 滚动箭头；列表视图上下滚动（隐藏滚动条）。
- 架内图标拖动 = 互换位置（拖 A 到 B 上两格互换），带 `reorderSeq` 防乱序。
- 双击打开文件；每个格子有「在文件夹中显示」按钮。
- 原文件被移走/删除后，条目仍留在架子上但会标为**失效**：格子置灰、文件名带删除线、显示「失效」小徽标，鼠标悬停提示「文件已不在：<原路径>」。点它会弹出中文说明「「文件名」已经不在了，可能被移走或删除。」并给一个「从架子上移除」按钮；失效条目的「在文件夹中显示」置灰不可点。失效状态是打开页面时按文件系统实时算出来的，不写进 `shelf.json`，文件放回原处后会自动恢复。
- 清空按钮带二次确认（第一次点变「确认清空？」，红底）。
- 系统原生图标：文件夹走 `SHGetFileInfo` 提真实图标，普通文件按扩展名缓存。

### 3. 通知（page 2）

- 读 Windows 通知中心历史库，定时轮询，解析标题/正文/来源应用。
- 相对时间显示（刚刚 / x分钟前 / …），每 30s 重算；加载时显示骨架条。
- **未读蓝点（美化-04，2026-11-11）**：未读条目（`order` 大于已读水位 `lastOrder`）在条目**最右端**显示一个 6px 蓝点（相对时间右边），扫一眼就能看出哪几条没读；点「已读」后蓝点当场消失（`markRead` 会重新拉一次列表拿新水位，只改状态消不掉）。`lastOrder` 是 `notify:list`/`notify:refresh`/`notify:clear-all` 新暴露的字段，判定逻辑与未读红点同源。**当天实机试过后去掉了原来的「打开」按钮**（用户反馈「点了没什么效果」）；要打开就展开到底层具体条目再点正文，正文本身就是「打开来源应用」。
- 点通知打开来源应用（映射不到的兜底打开 Windows 通知设置，自家通知聚焦灵动岛窗口）；「已读」按钮全部标记；「清空」按钮本地隐藏列表（按 order 水位过滤，旧通知不再重现，新通知照常）；收起态显示未读红点。
- **来源应用图标**：每条通知左侧显示应用图标小方块。解析链（`src/main/notifyIconStore.ts`）：自家→`build/icon.png`；UWP 应用→`Get-AppxPackage` 找包读 `AppxManifest` 的 `Square44x44Logo` 变体（优先 targetsize-48）；Win32 应用→App Paths 注册表 / 开始菜单 lnk 定位 exe 后 `SHGetFileInfo` 提 32px 图标；全失败退回文字徽标。结果缓存 `icon-cache/notify-<短名>.png`，失败不重试。
- **新消息到岛横幅**：通知轮询发现新到达消息（且未读未隐藏）时，收起态岛上方弹横幅（图标+应用名+标题），5 秒自动收回；展开态不弹；首轮拉取历史不弹；多条同时到达只显示最新一条（不做队列）。**2026-11-11 修掉一个真 bug**：原来只有「展开且停在通知页」时 `NotifyPanel` 才挂载并上抛未读数，停在别的页或收起态来新通知，铃铛上的「N 条未读通知」永远停在旧值（用户原话「刚刚有通知，通知栏没有反应」）；现在 `onNotifyArrived` 里每条到达都主动重拉一次 `notify:list` 更新铃铛数字。

### 4. 日程（page 3）

- 左侧月历（可翻月、今天高亮、有安排的日期标蓝点），右侧选中那一天的安排列表。
- **日历升级（美化-04，2026-11-11）**：今天用**蓝描边 + 蓝字**标识（`box-shadow: inset 0 0 0 1.5px #64b5f6`、`color: #8fc9fb`）。**第一版是白底黑字，用户当天实机看完原话「白色背景和黑点，太丑了」——白块在纯黑岛上太跳，已换成描边空心态**；今天又恰好被选中时加一圈浅色内描边（否则默认选中的就是今天、两者样式一样会看不出今天在哪）。有安排的日子在格子底部标一个 4px 蓝点（今天格子里是亮蓝点，选中格子里是浅色点，都不用黑色）。**格内不再显示日程文字标签**——第一版做成格内塞「时间 + 标题」小标签（最多 2 条、超出「+N」），2026-11-11 用户实机看过反馈「今天那行被撑高了、不对称」，改回「只标一个点」，格子高度恢复等高对称。`aria-label` 与「日期数字就是格子文本」都没变，e2e 依赖这两点。
- 加入文本 + 可选时间；时间用自绘深色面板选择（时钟按钮弹出，时/分两列，宽 132px，**不显示滚动条**、可用滚轮在两列里滚，点面板外收起）。
- 列表每条的勾选框是圆形（未完成细描边、已完成绿圈带勾），与待办页同款，勾上时有弹跳动画。
- **每条日程带日期**：在月历上点哪天就往哪天加；旧数据（没有日期字段）启动时迁到当天，迁移前自动备份 `schedule.json.bak-<时间戳>`。
- 列表排序：有时间在前、已完成在后；过期未完成标橙（`day` 早于今天或今天已过点），无时间但已过期显示「逾期」。
- **双击条目文字改名**（与待办页同款行内编辑）：回车或点别处提交，Esc 或清空视为取消；改名只动 `text`，不影响时间/日期/完成状态/提醒状态。
- 到点弹系统提醒（每 60s 检查，只提醒当天到点的条目）。
- 待办只在选中「今天」时与日程混排（带绿色徽标，可直接勾选）；选其他日期不显示待办，副标题写「待办只在今天」。

### 5. 收起态状态栏

- 显示：岛仔（16px）+ 时钟 + 电量圆环 + Wi-Fi 图标 + 待办剩余数字 + 未读红点。
- 电量圆环三态（2026-11-09）：**接着电源**→进度弧绿 `rgba(75, 214, 130, 0.9)`、提示「充电中 · 电量 X%」；**没插电且 ≤20%**→弧红 `rgba(255, 107, 107, 0.9)` + 数字红 `rgba(255, 107, 107, 0.95)`、提示「电量偏低 · X%」；其余→弧白、提示「电量 X%」。两者同占（如 15% 接着电）以充电为准，红色只在「没接电且 ≤20%」出现。阈值固定在 20%，无设置项。**充电判据**取「不是放电态」：`BatteryStatus` 不等于 `1`（放电中）且 `root\wmi` 没报 `Discharging=True`（`2` 表示接着交流电但没在充、`3` 表示已充满、`4/5` 表示低电/临界但插着电，对用户而言都算充电态——2026-11-09 三轮实测踩坑：旧判据 `-eq 2` 会在拔电后仍报绿，只认 `6/7/8/9` 又会在电池 96% 已停充时显示白弧，而排除 `4/5` 会让「插着电 + 15%」错走红态）。数据来源 `src/main/statusStore.ts` 的电量行，随 `status:snapshot` 返回。**刷新链路（2026-11-09 晚）**：主进程监听 Electron `powerMonitor` 的 `on-ac` / `on-battery` / `resume` 事件，事件到达后**当场**把充电态写进缓存并 `webContents.send('island:status-changed', snapshot)` 主动推给渲染层（颜色不等取数），300 ms 后再重读一次补百分比与 Wi-Fi；渲染层 `onStatusChanged` 收到即覆盖。另有 1 秒一次的 `powerMonitor.isOnBatteryPower()` 看门狗兜住「系统不发事件」的机器（只读 API、不起子进程）。另有 3 秒事件优先窗口（`EVENT_TRUST_MS`）：系统读数比事件慢、甚至短暂报旧方向时，以事件为准，避免「闪一下又弹回去」。因此插拔电源后颜色几十毫秒级翻转；主进程 30 秒缓存与渲染层 60 秒轮询保留作为最后兜底（事件与看门狗双双失灵时最坏仍约 90 秒，不会更差）。
- ✅ 时钟 ✅ 电量 ✅ Wi-Fi；⛔ 倒计时已否决不做（US-006，不是尚未排期，见 `docs/facts/用户角色与用户故事.md` 第五节 5.2）。
- 网络 / Wi-Fi 图标（US-005）：在电量环右侧、待办数字左侧。插网线显示网线水晶头图标，连 Wi-Fi 显示弧线信号图标；有网白色，连上了但上不了网（IPv4/IPv6 连接类别都不是 Internet）变橙，没联网不渲染。悬停提示按连接方式区分：「Wi-Fi：<网络名>（网络正常）」或「网线：<接口名>（网络正常）」。数据与电量同一次 PowerShell 子进程顺带取回（`Get-NetConnectionProfile` × `Get-NetAdapter` 按接口索引关联：介质类型 802.11=无线 / 802.3=有线且非虚拟网卡=网线，VPN 等虚拟网卡跳过；Wi-Fi 与网线并存优先网线；显式 UTF-8 输出防中文 SSID 乱码），随 `status:snapshot` 返回，缓存 30 秒；插拔电源触发的重读会连网络状态一起刷新并推送（与电量同一条广播），但网线插拔本身没有独立事件监听，仍靠缓存/轮询更新；展开态头部不显示。

### 6. 岛仔

- 呼吸动画、每 4.6s 眨眼。
- 开心 1.8s：弯眼 + 微笑 + 星星 + 弹跳；由勾掉待办或拖文件进岛触发。
- 支持 `prefers-reduced-motion`（系统开启减弱动效时停动画）。

### 7. 展开态通用

- 展开态保留顶部信息条：迷你岛仔 + 时钟 + 电量（绝对居中），不与右侧完成度/自启开关重叠。
- 页头彩色徽章 + 页名随页变化；`‹ ›` 翻页循环；底部圆点可点击跳页。
- Esc 收起；鼠标移出自动收起。

### 8. 开机自启

- 面板头部开关，写注册表 Run 键；自启时以收起态出现（`--hidden`）。

### 9. 退出与托盘

- 岛的任何位置（收起态或展开态）**点右键**弹出系统原生菜单，里面一项「退出灵动岛」，点它进程真正结束（不是只隐藏窗口）。
- 右下角通知区域有「灵动岛」托盘图标：鼠标悬停显示「灵动岛」，右键菜单同样有「退出灵动岛」；左键单击会把岛重新显示出来（多屏切换后找不到岛时用它找回）。图标可能被系统收进 `^` 溢出区。
- 退出前先停通知轮询（30 秒一次）与日程提醒（60 秒一次）两个定时器，避免退出瞬间弹出一条迟到提醒。

### 10. 数据导出（US-029，2026-11-06 已验收，合并 `d30e801`）

- 通知与置物架不导出（通知是只读外部库、置物架存本机路径）；导入功能未实现。
- 成功/失败用系统通知反馈（Electron Notification），同时设置窗口那一行下方也显示一行结果（路径或失败原因）；实现 ``src/main/exportStore.ts``。

### 11. 页面自定义（US-032，2026-11-06 已验收，合并 `4838aaa`）

- 右键/托盘菜单「页面管理…」→ 打开**独立设置窗口**并停在「页面管理」分区：勾选要显示的页面（4 个业务页，至少保留 1 页，最后一页锁定）、勾选收起态组件；「恢复默认」一键全开。（2026-11-11 `SPEC-settings-shell` 起，页面管理从岛的第 5 页搬进独立设置窗口，岛只剩 4 个轮播页。）
- 收起态组件共 6 项（美化-02 起含通知铃铛）：岛仔/时钟/电量/网络/待办数字/通知铃铛。**显隐与顺序都可调**——勾选框控制显示，按住任意一行拖到目标行上松手是**插入**：落在目标行上半插到它前面、落在下半插到它后面，其余组件顺移（2026-11-08 用户验收反馈从「互换」改为「插空放」，悬停时目标行边缘显示绿线提示落点）。胶囊上的组件顺序立刻跟着变。顺序存 `prefs.json` 的 `pagesCustom.order`；旧版偏好没有该字段时按默认顺序 `电量 → 岛仔 → 时钟 → 网络 → 待办 → 铃铛` 补全，不丢组件。
- **页面区的拖拽语义与上面一致（2026-11-11 用户修正）**：4 个业务页的排序同样是**插入**而不是「互换」——拖到目标行上半插到它前面、下半插到它后面，其余页顺移，悬停时同样出绿线提示。顺序存 `pagesCustom.pages`。（此前是互换语义，用户看过装机版后要求统一。）
- 铃铛的「有未读才出现」语义不变：勾着且无未读仍不显示。
- **铃铛可点（2026-11-10 用户要求）**：点收起态胶囊上的铃铛 = 展开岛并**直接跳到通知页**（第 3 页），省掉「先展开到待办页再翻两下」；展开态头部那枚铃铛同样生效（两处共用 `renderStatusItem`）。点击带 `stopPropagation`，不会被岛根节点的「收起态点击展开」逻辑吃掉；切页后按非首页口径 4000 ms 计时；键盘可聚焦，`Enter` / `Space` 等同点击。无未读时铃铛不渲染，因此也无从点击——这是既有语义。
- **展开态头部同步（美化-03，2026-11-08）**：点开岛后的头部同样按这套 `pagesCustom`（显隐 + 顺序）渲染，不再是写死的「岛仔 + 时钟 + 电量」。头部中间为上下两层——上层是岛仔单独一层（不参与排序，用户明确「岛仔除外」），下层是信息行，按 `order` 从左到右排电量环/时钟/网络/待办剩余/铃铛，与收起态同一份渲染实现、同一组类名；「无数据不渲染」语义也一致。左侧页面徽章+页名、右侧自启开关、待办页右侧 `已完成/总数`（`0/0`）位置不变。
- 偏好存 `%APPDATA%\lingdong-island\prefs.json`（主进程 ``src/main/prefsStore.ts``，IPC ``prefs:get``/``prefs:set``，非法值自动回落默认），跨重启保留。轮播只在保留页内循环；当前页被裁时自动跳到第一个保留页。
- 页面管理面板本身不进轮播（唯一入口是菜单「页面管理…」，2026-11-11 起在独立设置窗口里）。另设「常规」分区：开机自启开关（与岛头部胶囊共用同一份 IPC）、版本号、「打开数据文件夹」按钮。
- 关键决策：界面偏好**不用 localStorage**——2026-11-06 实测 file:// 来源的 localStorage 跨进程重启不持久化（SIGTERM 与优雅退出后均丢失，会话内有效），故页面自定义（US-032）与置物架视图记忆（US-035，早期版本曾误用 localStorage；US-037 已迁移）统一走 `prefs.json`：`pagesCustom` 管页面显隐与收起态组件顺序，`shelfView` 管四档视图，两字段互不覆盖。三道白名单与旧结论作废说明见 `docs/facts/数据规则.md` 第 5 条。

### 12. 通知页改进（2026-11-06 已验收，合并 `8881ff5`）

- 「已读」按钮：标记全部已读，收起态红点消失；防御——cached 为空时不动已读水位，避免红点被旧通知弹回。
- 「清空」按钮（新增）：列表立即清空，之后旧通知不再重现（`notif-read.json` 的 `hiddenUntil` 水位过滤，系统通知库只读不动），新通知照常显示。数据规则见 `docs/facts/数据规则.md`。
- 点击单条通知：能映射到的应用直接打开（新增：屏幕截图 ScreenSketch → 截图工具、自家通知 → 聚焦灵动岛窗口）；映射不到的**兜底打开 Windows 通知设置**（`ms-settings:notifications`），保证点击必有反应；点击后红点消失。

### 13. 打包安装

- electron-builder + NSIS，可改安装目录，桌面快捷方式，产物在 `release/`。
- 安装位置：图形界面安装时可以自己选目录；**静默安装（`/S`）不复用上次的目录**，默认落到 `%LOCALAPPDATA%\Programs\lingdong-island`，要用 `/D=<路径>` 显式指定（`/D=` 必须放在参数最后）。
- 卸载提示：卸载向导的欢迎页和完成页都用中文写明「只删程序、不删数据、数据在 `%APPDATA%\lingdong-island`、重装自动读回」，由 `build/installer.nsh` 提供（electron-builder 自动 include 该文件）。

### 14. 全屏自动避让（US-041，判据 2026-11-08 修正）

- 前台出现全屏应用时岛自动隐藏，避免挡画面；隐藏期间把鼠标移到屏幕最顶边（4px 感应带）可临时唤回，移开自动回隐。右键菜单「暂时隐藏」是另一条独立路径（摸边无效，托盘图标恢复）。
- **全屏判据**（`src/main/fullscreenWatch.ts` 的 `watchScript()`，每 1 秒一个短命 PowerShell 子进程）：前台窗口**可见** ∧ **未被 DWM cloak** ∧ 类名不属于已知壳层（`Progman`/`WorkerW`/`Shell_TrayWnd`/`Windows.UI.Core.CoreWindow` 等）∧ 不是本进程窗口 ∧ 矩形覆盖整个主屏。
- 2026-11-08 修正：原判据只看「矩形覆盖主屏」，把两类**不是全屏应用**的窗口也算成全屏，导致用户没开全屏岛却自己消失——① DWM 已 cloak 的 `TextInputHost`（类名 `Windows.UI.Core.CoreWindow`，rect 铺满整屏但用户根本看不见）；② 桌面 `Progman`（点桌面时它成为前台）。同时修掉「判定值不翻转就不动作」导致前台恢复后岛不自动回来的问题。
- 本机 `PrimaryScreen.WorkArea` 与 `Bounds` 相同（任务栏自动隐藏），因此**最大化占满屏幕的普通应用仍会触发隐藏**，这是 US-041 的原始设计，本轮作为回归保护未改动。
- 验证：`scripts/e2e-fullscreen-misjudge.mjs`（7 条，覆盖 cloak 壳层 / 桌面 / 最大化 / 真全屏 / 恢复）、`scripts/e2e-fullscreen-avoid.mjs`（既有 A1-A7）。
