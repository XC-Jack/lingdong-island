## 逐项说明

### 1. 待办清单（page 0）

- 这一页的定位是「今天要做什么」的速览：列表 = 所有待办 + **今天**的日程混排。明天的、昨天的日程都不出现在这里（要看别的日期去日程页）。
- 增加、勾选完成、删除、双击行内改名（空文本取消改名）。
- 完成度大号显示 `已完成数/总数`（如 `2/3`），这个总数把待办和今天的日程一起算。
- 勾选时 ✓ 有 `check-pop` 弹跳动画（180ms），触发岛仔开心。
- 加完一条后输入框保持焦点，可连续录入。
- 列表没有条数上限；内容超过岛高度上限（420px）后列表在岛内滚动（不显示滚动条），新加的一条会自动滚到底部进入视野（2026-11-05 修复，此前超长部分会溢出窗口被裁掉、看起来像「加不上」）。
- 在这一页加的内容存为**今天的日程**（不是待办）：今天在待办页和日程页都能看到，明天从待办页消失、仍留在日程页今天那一格。加的时候可以点右边的钟选一个时间，也可以不选。
- 列表里的日程条目：有时间的左侧显示 `09:00` 这样的时间徽标（只显示几点几分，不显示日期），过点还没完成的徽标变橙；可以直接勾选，勾选结果与日程页同步。
- 列表里的待办条目：与以前一样，没有时间徽标，双击可改名。
- 收起态就能看今天还剩几件：矮条最右侧（电量环右边、未读红点左边）只显示一个绿色数字 N（N = 待办 + 今天的日程里未完成的件数），不带图标。鼠标悬停提示「今天还有 N 件没做完（共 M 件）」。全部做完或一条都没有时这块不显示，不占地方。数字在「首次启动」和「每次从展开态收回」时各现算一次（不轮询），所以勾完一条收回就能看到数字减一。

### 2. 置物架（page 1）

- 拖入文件即暂存（整岛接收拖放），自动去重，持久化。
- 四种视图：大图标 84px / 中图标 64px / 小图标 48px / 列表；点击工具条按钮弹出菜单选择（不是循环切换）。
- 视图选择会记住（US-037 起）：选完写进主进程 `prefs.json` 的 `shelfView` 字段（经 `prefs:get`/`prefs:set` IPC），重启应用后仍是上次那个视图；从来没选过、或者值被改坏，都回落「大图标」，不报错。早期版本存渲染层 localStorage，跨重启会丢（见 US-037）。
- 图标视图横向胶片条，放不下时两侧出现 `‹ ›` 滚动箭头；列表视图上下滚动（隐藏滚动条）。
- 架内图标拖动 = 互换位置（拖 A 到 B 上两格互换），带 `reorderSeq` 防乱序。
- 双击打开文件；每个格子有「在文件夹中显示」按钮。
- 原文件被移走/删除后，条目仍留在架子上但会标为**失效**：格子置灰、文件名带删除线、显示「失效」小徽标，鼠标悬停提示「文件已不在：<原路径>」。点它会弹出中文说明「「文件名」已经不在了，可能被移走或删除。」并给一个「从架子上移除」按钮；失效条目的「在文件夹中显示」置灰不可点。失效状态是打开页面时按文件系统实时算出来的，不写进 `shelf.json`，文件放回原处后会自动恢复。
- 清空按钮带二次确认（第一次点变「确认清空？」，红底）。
- 系统原生图标：文件夹走 `SHGetFileInfo` 提真实图标，普通文件按扩展名缓存。

### 3. 通知（page 2）

- 读 Windows 通知中心历史库，定时轮询，解析标题/正文/来源应用。
- 相对时间显示（刚刚 / x分钟前 / …），每 30s 重算；加载时显示骨架条。
- 点通知打开来源应用（映射不到的兜底打开 Windows 通知设置，自家通知聚焦灵动岛窗口）；「已读」按钮全部标记；「清空」按钮本地隐藏列表（按 order 水位过滤，旧通知不再重现，新通知照常）；收起态显示未读红点。
- **来源应用图标**：每条通知左侧显示应用图标小方块。解析链（`src/main/notifyIconStore.ts`）：自家→`build/icon.png`；UWP 应用→`Get-AppxPackage` 找包读 `AppxManifest` 的 `Square44x44Logo` 变体（优先 targetsize-48）；Win32 应用→App Paths 注册表 / 开始菜单 lnk 定位 exe 后 `SHGetFileInfo` 提 32px 图标；全失败退回文字徽标。结果缓存 `icon-cache/notify-<短名>.png`，失败不重试。
- **新消息到岛横幅**：通知轮询发现新到达消息（且未读未隐藏）时，收起态岛上方弹横幅（图标+应用名+标题），5 秒自动收回；展开态不弹；首轮拉取历史不弹；多条同时到达只显示最新一条（不做队列）。

### 4. 日程（page 3）

- 左侧月历（可翻月、今天高亮、有安排的日期标蓝点），右侧选中那一天的安排列表。
- 加入文本 + 可选时间；时间用自绘深色面板选择（时钟按钮弹出，时/分两列，宽 132px，**不显示滚动条**、可用滚轮在两列里滚，点面板外收起）。
- 列表每条的勾选框是圆形（未完成细描边、已完成绿圈带勾），与待办页同款，勾上时有弹跳动画。
- **每条日程带日期**：在月历上点哪天就往哪天加；旧数据（没有日期字段）启动时迁到当天，迁移前自动备份 `schedule.json.bak-<时间戳>`。
- 列表排序：有时间在前、已完成在后；过期未完成标橙（`day` 早于今天或今天已过点），无时间但已过期显示「逾期」。
- **双击条目文字改名**（与待办页同款行内编辑）：回车或点别处提交，Esc 或清空视为取消；改名只动 `text`，不影响时间/日期/完成状态/提醒状态。
- 到点弹系统提醒（每 60s 检查，只提醒当天到点的条目）。
- 待办只在选中「今天」时与日程混排（带绿色徽标，可直接勾选）；选其他日期不显示待办，副标题写「待办只在今天」。

### 5. 收起态状态栏

- 显示：岛仔（16px）+ 时钟 + 电量圆环（`≤20%` 变红）+ Wi-Fi 图标 + 待办剩余数字 + 未读红点。
- ✅ 时钟 ✅ 电量 ✅ Wi-Fi ⬜ 倒计时。
- 网络 / Wi-Fi 图标（US-005）：在电量环右侧、待办数字左侧。插网线显示网线水晶头图标，连 Wi-Fi 显示弧线信号图标；有网白色，连上了但上不了网（IPv4/IPv6 连接类别都不是 Internet）变橙，没联网不渲染。悬停提示按连接方式区分：「Wi-Fi：<网络名>（网络正常）」或「网线：<接口名>（网络正常）」。数据与电量同一次 PowerShell 子进程顺带取回（`Get-NetConnectionProfile` × `Get-NetAdapter` 按接口索引关联：介质类型 802.11=无线 / 802.3=有线且非虚拟网卡=网线，VPN 等虚拟网卡跳过；Wi-Fi 与网线并存优先网线；显式 UTF-8 输出防中文 SSID 乱码），随 `status:snapshot` 返回，缓存 30 秒；展开态头部不显示。

### 6. 岛仔

- 呼吸动画、每 4.6s 眨眼。
- 开心 1.8s：弯眼 + 微笑 + 星星 + 弹跳；由勾掉待办或拖文件进岛触发。
- 支持 `prefers-reduced-motion`（系统开启减弱动效时停动画）。

### 7. 展开态通用

- 展开态保留顶部信息条：迷你岛仔 + 时钟 + 电量（绝对居中），不与右侧完成度/自启开关重叠。
- 页头彩色徽章 + 页名随页变化；`‹ ›` 翻页循环；底部圆点可点击跳页。
- Esc 收起；鼠标移出自动收起。

### 8. 开机自启

- 面板头部开关，写注册表 Run 键；自启时以收起态出现（`--hidden`）。

### 9. 退出与托盘

- 岛的任何位置（收起态或展开态）**点右键**弹出系统原生菜单，里面一项「退出灵动岛」，点它进程真正结束（不是只隐藏窗口）。
- 右下角通知区域有「灵动岛」托盘图标：鼠标悬停显示「灵动岛」，右键菜单同样有「退出灵动岛」；左键单击会把岛重新显示出来（多屏切换后找不到岛时用它找回）。图标可能被系统收进 `^` 溢出区。
- 退出前先停通知轮询（30 秒一次）与日程提醒（60 秒一次）两个定时器，避免退出瞬间弹出一条迟到提醒。

### 10. 数据导出（US-029，2026-11-06 已验收，合并 `d30e801`）

- 右键/托盘菜单第一项「导出数据…」→ 系统原生另存为对话框（默认文件名 ``灵动岛备份-YYYYMMDD-HHmmss.json``、默认目录「文档」）→ 把待办与日程写成一份 JSON 备份（含 ``app``/``version``/``exportedAt`` 头）。
- 通知与置物架不导出（通知是只读外部库、置物架存本机路径）；导入功能未实现。
- 成功/失败用系统通知反馈（Electron Notification）；实现 ``src/main/exportStore.ts``，入口在 ``buildAppMenu()``。

### 11. 页面自定义（US-032，2026-11-06 已验收，合并 `4838aaa`）

- 右键/托盘菜单「页面管理…」→ 展开岛切到页面管理面板：勾选要显示的页面（4 个业务页，至少保留 1 页，最后一页锁定）、勾选收起态 5 个组件（岛仔/时钟/电量/网络/待办数字，未读红点不可关）；「恢复默认」一键全开。
- 偏好存 `%APPDATA%\lingdong-island\prefs.json`（主进程 ``src/main/prefsStore.ts``，IPC ``prefs:get``/``prefs:set``，非法值自动回落默认），跨重启保留。轮播只在保留页内循环；当前页被裁时自动跳到第一个保留页。
- 页面管理面板本身不进轮播（唯一入口是菜单「页面管理…」）。
- 关键决策：界面偏好**不用 localStorage**——file:// 来源的 localStorage 跨进程重启不持久化（2026-11-06 实测：SIGTERM 与优雅退出后均丢失，会话内有效）。~~US-035 置物架视图记忆仍用 localStorage，同样受此影响（另开故事修）~~ → 2026-11-07 US-037 已修：视图记忆同样走 `prefs.json`（`shelfView` 字段，与 pagesCustom 互不覆盖）。

### 12. 通知页改进（2026-11-06 已验收，合并 `8881ff5`）

- 「已读」按钮：标记全部已读，收起态红点消失；防御——cached 为空时不动已读水位，避免红点被旧通知弹回。
- 「清空」按钮（新增）：列表立即清空，之后旧通知不再重现（`notif-read.json` 的 `hiddenUntil` 水位过滤，系统通知库只读不动），新通知照常显示。数据规则见 `docs/facts/数据规则.md`。
- 点击单条通知：能映射到的应用直接打开（新增：屏幕截图 ScreenSketch → 截图工具、自家通知 → 聚焦灵动岛窗口）；映射不到的**兜底打开 Windows 通知设置**（`ms-settings:notifications`），保证点击必有反应；点击后红点消失。

### 13. 打包安装

- electron-builder + NSIS，可改安装目录，桌面快捷方式，产物在 `release/`。
- 安装位置：图形界面安装时可以自己选目录；**静默安装（`/S`）不复用上次的目录**，默认落到 `%LOCALAPPDATA%\Programs\lingdong-island`，要用 `/D=<路径>` 显式指定（`/D=` 必须放在参数最后）。
- 卸载提示：卸载向导的欢迎页和完成页都用中文写明「只删程序、不删数据、数据在 `%APPDATA%\lingdong-island`、重装自动读回」，由 `build/installer.nsh` 提供（electron-builder 自动 include 该文件）。

## 需求清单（视频逐帧还原，作为长期参照）

> 来源：对 B 站参考视频逐帧抽帧（fps=1，104 帧）。这是**原视频有、本项目未全部实现**的完整对照表，用于判断后续要做什么。

- 收起态：电量、Wi-Fi、时间、App 图标（带角标）、倒计时、验证码提示（**已实现，US-039**：复制验证码后收起态弹紫色横幅 8 秒，详见 docs/Spec/SPEC-us-039-code-hint.md）、歌词条。
- 通知页：App 图标 + 大号时间 + 标题 + 右上药丸「90 分钟后」+ 分隔线 + 日期 + 「查看」按钮。
- 置物架页：标题 + 时钟 + 日期 + 「添加」按钮 + 虚线投放区。
